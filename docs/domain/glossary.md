# 用語集

> このプロダクトで使う言葉を1か所に。**画面の文言・コードの名前・仕様・会話で同じ言葉を使う**ためのもの。
> 新しい言葉が出てきたら、使い始める PR でここに1行足す(`/update-domain-docs` スキル)。

| 日本語 | コードでの名前 | 意味 | 例 |
|---|---|---|---|
| 組織 | `tenant`(`tenant_id`) | 使う会社の単位。データは組織ごとに分かれ、他の組織からは見えない | Acme 株式会社 |
| 他社 | `other_tenant` | 自分の組織ではない組織。権限の表では「他社からは 404」 | Acme から見た Globex |
| 利用者 | `user` | 組織の中の人。いまは1人が1つの組織にだけ入る | admin@acme.test |
| ロール | `role` | 利用者の役割。admin / member / viewer の3つ | — |
| 管理者 | `admin` | 何でもできる。プロジェクトを消せるのは管理者だけ | — |
| メンバー | `member` | プロジェクトとタスクを作る・直す。プロジェクトは消せない | — |
| 閲覧者 | `viewer` | 見るだけ | — |
| プロジェクト | `project` | タスクのまとまり。組織の中にある | 春の新機能 |
| タスク | `task` | プロジェクトの中のやること。完了か未完了 | 見積もりを出す |
| 完了 | `done`(true) | タスクを終えた状態。画面では線を引く | — |
| セッション | `session` | ログインしている間の「誰が・どの組織か」。署名つきの Cookie。何もしなければ1時間・使い続けても12時間で切れる(ADR 0017) | — |
| 二段階認証 | `mfa`(TOTP) | パスワードの後に、認証アプリの6桁のコードを聞くこと。正は Cognito、アプリは写し(`users.mfa_enabled`)を持つ | Google Authenticator |
| 二段階認証の必須 | `mfa_required` | 組織の管理者が「全員に二段階認証を」と決めること。未設定の人は設定の画面へ回される(設定待ち) | — |
| 確かめ直し | `reauth` | 大事な所(二段階認証・メール・パスワード)を変える前に、パスワード(とコード)を入れ直すこと。10分だけ有効の札になる | — |
| ほかの端末を切る | `sessions_valid_after` | パスワードなどを変えたとき、それより前にログインした端末・ブラウザのセッションを使えなくすること | — |
| 権限 | `permission` | 操作ごとの「してよいか」。`apps/api/src/authz/policy.ts` | `task:write` |
| 権限の表 | `docs/authz/matrix.yaml` | 誰が・どの API を・叩くと・どうなるべきかの表 | — |
| サポートへの許可 | `support_grant` | 組織の管理者が「サポートに見せてよい」を期限つきで出したもの。取り消せる | 24時間だけ許可する |
| サポート番号 | `code` | 許可を出したときに1回だけ出る12桁(4桁ずつ)。社員はこれで入る。保存しない | `K7QM-2XPA-9DNE` |
| 代理ログイン | `support session` | 運営の社員が、許可された組織を閲覧者として見ている間。最長1時間 | — |
| 運営の組織 | `SUPPORT_TENANT_ID` | 社員が所属する組織。ここの人だけが代理ログインできる | 運営(サポート) |
| データの書き出し | `export` | 管理者が自社のデータを1つの JSON で受け取る。秘密と他社の物は入らない | 解約の前に書き出す |
| 開通(組織を作る) | `create-tenant` | 申し込みを受けた会社を、運営がコマンドで組織にし、最初の管理者を作る。試し → 名前の確認 → 実行 | — |
| 招待 | `invitation` | 管理者がメールアドレスとロールで人を招くこと。リンクは7日・1回きり・取り消せる。受けると、その組織に人ができる | 職人をメンバーとして招く |
| プラン(契約) | `tenant_plans` | 組織が契約しているプラン・人数の上限・どの版の価格表か・据え置きの期限。足すだけで、運営がコマンドで変える。金額は持たない | スタンダード・10人まで |
| 据え置き | `price_locked_until` | 値上げのあとも、決めた日まで旧版の価格表のままにすること。プランを変えると消える | 2027年12月まで旧価格 |
| 解約(組織の削除) | `delete-tenant` | 契約が終わった組織のデータを、運営がコマンドで消す。戻せない | — |
| 監査ログ | `audit_events` | 誰が・いつ・何をしたかの記録。足すだけで直せない・消せない。管理者だけが見られる | プロジェクトを消した |
| 利用規約・プライバシーポリシー | `terms` / `privacy` | 版つきの文書。本文はリポジトリの Markdown、版の一覧は `LEGAL_VERSIONS` | 利用規約の版 2 |
| 同意し直し | `reconsent` | その版が効いたら、同意していない人を同意の画面へ回す(利用者に不利になりうる変更など) | — |
| 同意の記録 | `legal.consents` | 誰が・どの版に・いつ・どの画面から・組織としてか本人としてか。足すだけ | 管理者が組織として同意した |
| 種データ | `seed` | 開発・プレビュー用の2社分のデータ。本番には入れない | — |
| 事前登録 | `pre_registration` | 公開の LP で、提供開始の案内と試しの利用の招待を受けるために、会社名とメールアドレスを預けること。運営の組織の持ち物(docs/domain/growth) | — |
| 確認のメール | `confirm`(ダブルオプトイン) | 事前登録の後に届くメール。リンクを開くまで案内を送らず、組織にもできない | — |
| 来た所 | `utm_source` など(UTM) | 呼んだリンクに付けた印。どの届け方から来たかを数える | `?utm_source=koumuten-kai` |

## 言葉の決まり

- 画面では「組織」、コードでは `tenant`。**「会社」「テナント」は画面では使わない**(説明の文の中だけ)。
- 「消す」は戻せない操作。戻せるもの(アーカイブなど)を作るときは、別の言葉を決めてここに足す。
- ロールの名前は画面では日本語(管理者・メンバー・閲覧者)、API とコードでは英語。
