# 用語集

> このプロダクトで使う言葉を1か所に。**画面の文言・コードの名前・仕様・会話で同じ言葉を使う**ためのもの。
> 新しい言葉が出てきたら、使い始める PR でここに1行足す(`/update-domain-docs` スキル)。

| 日本語 | コードでの名前 | 意味 | 例 |
|---|---|---|---|
| 組織 | `tenant`(`tenant_id`) | 使う会社の単位。データは組織ごとに分かれ、他の組織からは見えない | Acme 株式会社 |
| 他社 | `other_tenant` | 自分の組織ではない組織。権限の表では「他社からは 404」 | Acme から見た Globex |
| 利用者 | `user` | 組織の中の人。いまは1人が1つの組織にだけ入る | admin@acme.test |
| ロール | `role` | 利用者の役割。admin / member / viewer の3つ | — |
| 管理者 | `admin` | 何でもできる。プロジェクトを消せるのは管理者だけ | — |
| メンバー | `member` | プロジェクトとタスクを作る・直す。プロジェクトは消せない | — |
| 閲覧者 | `viewer` | 見るだけ | — |
| プロジェクト | `project` | タスクのまとまり。組織の中にある | 春の新機能 |
| タスク | `task` | プロジェクトの中のやること。完了か未完了 | 見積もりを出す |
| 完了 | `done`(true) | タスクを終えた状態。画面では線を引く | — |
| セッション | `session` | ログインしている間の「誰が・どの組織か」。署名つきの Cookie | — |
| 権限 | `permission` | 操作ごとの「してよいか」。`apps/api/src/authz/policy.ts` | `task:write` |
| 権限の表 | `docs/authz/matrix.yaml` | 誰が・どの API を・叩くと・どうなるべきかの表 | — |
| 監査ログ | `audit_events` | 誰が・いつ・何をしたかの記録。足すだけで直せない・消せない。管理者だけが見られる | プロジェクトを消した |
| 種データ | `seed` | 開発・プレビュー用の2社分のデータ。本番には入れない | — |

## 言葉の決まり

- 画面では「組織」、コードでは `tenant`。**「会社」「テナント」は画面では使わない**(説明の文の中だけ)。
- 「消す」は戻せない操作。戻せるもの(アーカイブなど)を作るときは、別の言葉を決めてここに足す。
- ロールの名前は画面では日本語(管理者・メンバー・閲覧者)、API とコードでは英語。
