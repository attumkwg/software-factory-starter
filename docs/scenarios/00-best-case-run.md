## 📌 当時の結論(2026-10-25)

> 2026-10-26 に、ここで見つけた穴(G-27〜G-39)は全部済みになった。下は当時の結論(場面ごとの今の判定は [README.md](README.md) の一覧と [gaps.md](gaps.md))。

- **最高の想定なら、作って出すまでは回る**。計画・話の記録・賭け・試作は、キットの形のまま検査を通った。
- **つまずくのは「作る前」と「売る前」**。最高の想定でも、次の4つで止まるか、決めずに進んでしまう: 買う人と使う人の区別・創業者の腹落ち・継続率の数え方・売り文句から LP と色を決める段。
- **「それでもやる」は止まらない**。撤退の線に当たった賭けを「進む」と書いても、検査は通った。止めないのは正しいが、意思で進んだことが残らない。

## 最高の想定でも先に足したい物

1. G-30 買う人・使う人・決める人(`/kickoff` と話の記録の型)
2. G-27 なぜ自分たちか(FPF の問い)
3. G-29 意思で進む、を残す形
4. G-28 継続率(同じ組織が使い続けたか)
5. G-31 → G-32 → G-33 約束と売り文句 → ブランドと色 → LP

この順は「安く直せて、後から直すと高い順」。1〜3 は文書と型だけ、4 は数え方の追加、5 は新しいスキルと、公開してよい LP の型。
