# フィットジャーニーと「決めること」の地図

> 入口は [README.md](README.md)。何を作るかを決める所から売り始めるまでに、**何を・どの順で決めるか**と、それがキットのどこに残るか。
> フィットジャーニー(CPF → FPF → PSF → SPF → PMF)は**目安で、関所ではない**。線に届かなくても「それでもやる」と決めてよい。そのときは、引き受けた危なさと止める線だけを残して進む(下の「それでもやる」)。
> 印: ✅ キットにある / 🟡 一部ある / ❌ 無い(番号は [gaps.md](gaps.md))。

## 📌 当時の結論(2026-10-25)

> 2026-10-26 に、ここで見つけた穴(G-27〜G-39)は全部済みになった。下は当時の結論(場面ごとの今の判定は [README.md](README.md) の一覧と [gaps.md](gaps.md))。

- **作る段(PSF → PMF)は回るが、その手前と、売る段が薄い**。創業者の腹落ち(FPF)と、続けて提供できるか(SPF)の段が無い。継続率(同じ組織が使い続けたか)も数えられない。
- **「売れる言葉」が決まらないと、LP もブランドの色も決まらない**。言葉の元は CPF(誰の・どんな困りごと・いまの代わり)と PSF(何が効いたか)にあるのに、そこから売り文句・LP・色へつなぐ段が無い。
- **「それでもやる」はいまも止められない**(賭けは撤退の線に当たっても「進む」と書けば通る)。ただし、意思で進んだことが記録に残らない。止めない仕組みのまま、**残す形**だけを足す。

## 1. 段ごとに決めること

| 段 | 終わりの目安 | 決めること | キットのどこ |
|---|---|---|---|
| CPF 顧客と課題 | 顧客の像・課題とその背景・いまの代わりがはっきり | 誰が(**買う人・使う人・決める人**)/ 何に困るか / いまどうしているか / いちばん危ない思い込み / 合格と撤退の線 | ✅ `/kickoff`・`plan.md`・`interviews/`(買う人・使う人・決める人も。G-30 済み) |
| FPF 創業者と課題 | 創業者とメンバーが腹落ちしている | なぜ自分たちか(強み・つながり)/ 何年やり続けるか / やめる条件 | ✅ `/kickoff` の A の 5・`plan.md` の「なぜ自分たちか」(G-27 済み) |

## 2. 決める順番(言葉 → LP → 色)

```
CPF で分かったこと(相手の言葉)         PSF で分かったこと(何が効いたか)
   誰の・どんな困りごと・いまの代わり      アーリーアダプターがよく言った一言
                 └───────────┬───────────┘
                    約束(1行)・売り文句・代わりとの違い   ← ここが決まってから
                             │
             ┌───────────────┼───────────────┐
         LP の見出しと中身     ブランド(名前・トーン・色)   営業の資料・広報の文
```

- **色や名前から決めない**。約束が決まる前に色を決めると、LP もプロダクトも「合わない物」になる。
- 約束の材料は、キットの中にもう溜まる: `interviews/`(相手の言葉)・賭けの小石(何が効いたか)・`plan.md`(代わりの物と不満)。
- 色は、約束と相手(例: 現場の職人・病院の情シス)から**案を2〜3つ**出し、トークン(`packages/ui/src/tokens.css`)に置き換えて、コントラストの検査(axe)と VRT で確かめる。決めるのは人。

## 3. それでもやる(意思で進める)

- フィットジャーニーの線は目安。届かなくても、**本人が決めれば進んでよい**(キットは止めない)。
- 進むときに残す物は3つだけ: **引き受けた危なさ**(何が外れたら全部むだになるか)・**止める線**(どうなったらやめるか。期限つき)・**決めた人**。
- 置き場所: 賭けなら小石の判断に `意思で進む(@名前)` と「意思で進んだ判断」の表、全体の計画なら `plan.md` の「これまでの判断」と同じ形の表。`pnpm bets` は意思で進んだ賭けを ⚑ で一覧に出し、止める線の期限を過ぎたら ⏰ で知らせる(G-29 済み・ADR 0035)。
- 足す前は「進む」と書けば通り、**線を越えて進んだのか、意思で進んだのかが区別できなかった**(2026-10-25 の通しの試しで確かめた。[00-best-case-run.md](00-best-case-run.md))。
