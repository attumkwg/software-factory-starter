# 9. 外から来た人が、このキットを選ぶか(刺さるか・使いやすいか・分かりやすいか)

> 入口は [README.md](README.md)。01〜08 は「キットを使う会社の中で回るか」。この場面は手前の「**キットを見つけた人が、使うと決めるか**」を見る。
> 2026-10-27 に、作った経緯を知らない4人の立場で README から読み、コードとスキルまで確かめた(1人は手元で `pnpm install`・`pnpm test` も流した)。あわせて、似ている雛形と需要を調べた(📚)。見つけた穴は [gaps.md](gaps.md) の G-40〜G-57。

## 📌 いまの結論(2026-10-27)

- **考え方は刺さる。4人のうち3人が「刺さる」に4点を付けた**: AI の事故を「お願い」ではなく手段で止める・人が見るのは判断が要る所だけ・作る前に確かめる・日本の会社向けに売るときの質問票と ISMS。個人の副業(月1万円)には刺さらない(想定どおり)。
- **使いやすさは4人とも2点。全員が最初に止まったのはライセンス**(README の3行目「複製・改変はご遠慮ください」・LICENSE が無い。→ G-40 で MIT にした)。次に、保守の約束と上流の更新の取り込みが無いこと、重さ(部品69・文書300超・消すのは1つずつ)、**既存の会社や既存のリポジトリに一部だけ入れる道が無い**こと。
- **分かりやすさは平均2.75点**。README の頭(向き不向き・費用・立場ごとの入口)は全員が褒めた。奥が深すぎる・独自の言葉が多い・入口の文書どうしが食い違う。
- **中身は「言っているとおり」だった所が多い**(RLS を書き忘れても漏れない重ね方・認可の表と OpenAPI の突き合わせ・守るパスの一覧1つを3つの層が見る)。ただし **「危険度『高』は2人」は GitHub の設定では強制できていない**・守るパスに抜けがある・看板の A 社の「写真」を置く部品が無い。
- **採用の判断は4人とも「一部だけ持ち帰る」か「使わない」**。丸ごと使う人はいなかった。ライセンスを決めて、入口を1本にし、一部だけ入れる道を作るのが先(足す順番の案は [gaps.md](gaps.md) の「外の人に届ける前」)。

## 9-6 「これは他に無い」と言われた所

- 🧱 **RLS を書き忘れても漏れない重ね方**と、全表を確かめるテスト(CTO)。
- 🗂 **危ない場所の一覧が1つで、手元のフック・PR のラベル・CODEOWNERS が同じ一覧を見る**。ずれたら CI が落ちる(CTO・EM)。
- 🧩 **部品のカタログと `/tailor`**: 部品ごとに「消せるか・頼られている部品・法令・消し方」を持ち、顧客に合わせて削る作業が仕組みになっている(技術顧問)。
- ✋ **「導入時に決める」**: キットの仮の既定値を、使う会社が承認しないと本番に出せない(技術顧問)。
- 📋 **質問票は「本番で確かめた物だけ『はい』」**・営業の資料一式・SoA の生成・要配慮個人情報の分離(全員。日本の会社向けにここまである物は見当たらない)。
- 🗓 **段階ごとの点検の台帳**と、任せる範囲を広げる条件・戻す条件を数字で先に決める所(技術顧問・EM)。

## 9-7 📚 世の中では(似ている物と、雛形が捨てられる理由)

- **似ている物は3つの群**: ① 有料・無料の SaaS の雛形(買い切り 約3万〜20万円。ほぼ Next.js+Vercel/Supabase。会社向けの守りは SSO・監査ログまで)② AI の開発の型・スキル集(スターが数万〜数十万と、雛形より桁が大きい。アプリは持たない)③ AWS 公式の SaaS の部品(CDK。アプリと AI の型は無い)。**作る前の検証 → AI のライン → 会社向けの守り → 運用と会計を1つに持つ物は見当たらない**。日本語の会社向け SaaS の雛形も見当たらない。
- **雛形が捨てられる理由**: ① 要らない機能が多く剥がすのが重い ② 上流の更新が取り込めない ③ 技術の選び方が他人の好み ④ 手入れが止まる ⑤ 中身を分からないまま使い、壊れたときに直せない。**このキットは ① ② ⑤ に当たる**(G-42・G-48・G-49)。
- **伸びている物の配り方**: AI の型はプラグインやスキル集で配り、既存のリポジトリに足せる形。日本の作者で伸びた物は、英語の README を先に置き日本語版を添えている。
- **一番刺さりそうな相手**: 日本で AI 導入支援・受託をする会社や個人 / 中堅企業の新規事業(1〜15人・AWS が標準)/ 大企業に売る直前の会社向けスタートアップ。個人開発・B2C・Vercel の層は他の雛形の領域。
