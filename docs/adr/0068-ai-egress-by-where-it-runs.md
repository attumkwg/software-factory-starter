# ADR 0068: AI の外への通信は、送る手段を持たせないことと、AI が書いたコードを動かす所(絞った devcontainer・背景の AI)で絞る

- 状態: 採用(「② 背景の AI」の所は ADR 0069 で置き換え)
- 日付: 2026-10-25
- 決めた人: @attumkwg(2026-10-25。会話で回答。親のセッションから)

## 背景

- `docs/security.md` の AI-2(AI の環境から外に出られる先を絞る)が「未」。前に devcontainer で絞ったら、中から Docker が使えず、AI が結合テストと E2E を回せなくなって見送った。
- 人が見ていない所で AI を長く回すと、AI が書いたコードや、禁じていなかった道具(フォームの送信など)で外へ送っても気づけない(想定の場面 6-11・穴 G-22)。
- Claude Code の sandbox は Bash を OS の仕組みで囲めるが、Docker は sandbox の外でしか動かず、ネイティブの Windows では sandbox が動かない。

## 選択肢

| 案 | 良い所 | 弱い所 |
|---|---|---|
| A. devcontainer の firewall(IP を許す) | Docker があれば OS を問わない | 置き場の IP が変わると落ちる。前回は中の Docker を止めて壊れた |
| B. 許可リストのプロキシ+firewall の devcontainer | 名前で許す・記録が残る・中の Docker で結合テストが回る | 作りが少し増える(プロキシ・firewall・中の Docker の設定) |
| C. Claude Code の sandbox | 設定だけ・Bash を強く囲める | Docker を外に出すと絞りに穴。Windows で動かない |
| D. テストを CI に任せ、AI の環境に Docker を置かない | AI の環境を強く絞れる | 往復が数分延びる |
| E. 人が見ていない作業だけ絞る | 対話の速さを落とさない | 手元のそのままでは夜に回せない |

## 決めたこと

E の方針で、人が見ていない作業は **B の devcontainer(①)か、D の形の背景の AI(②)でだけ**回す。全部の AI について、外へ送る手段(MCP・Web を読む道具・ブラウザ・鍵)を棚卸しし、要る物だけにする。外へ向けた操作は記録し、PR に「外へ出した物」として並べ、頼まれていない物に印を付ける。C は結合テストを回さない作業の任意の層。詳しくは設計書 0057。

## 結果として起きること

- 良くなること: 人が見ていない所で AI を回せる。禁じていない手段で外へ送る道が、手段ごと無くなる。頼まれていない外向きの行動が PR で見える。
- 我慢すること: 背景の AI は調べ物ができず、テストの結果を CI で待つ。許可リストに無い宛先は PR で足すまで使えない。手元のそのままでは夜に回さない。
- 見直す合図: Claude Code の sandbox が Docker と組める形になったとき。背景の AI の往復の遅さが仕事を止めるようになったとき。
