# ADR 0035: フィットジャーニーは目安にし、線に届かなくても本人の意思で進める(止めずに残す)

- 状態: 採用
- 日付: 2026-10-25
- 決めた人: @attumkwg

## 背景

最高の想定で通しで回したら、試作の結果が撤退の線に当たっても「進む」と書けば先へ進めた(`docs/scenarios/00-best-case-run.md`)。止めないのはよいが、線を越えて進んだのか、意思で進んだのかが残らない。持ち主「フィットジャーニーは目安でしかないので、それでもやるんだという意思がある可能性があります。その場合も実施できるような仕組みにする必要はある」。

## 選択肢

| 案 | 良い所 | 弱い所 |
|---|---|---|
| A. 線に届かなければ止める(関所) | 思い込みで作り続けない | 本人の意思で賭ける道を塞ぐ。線を甘くして通す抜け道ができる |
| B. 止めずに、意思で進んだことを残す | 本人が決められる・後から理由と止める時が分かる | 止める線を守るかは人しだい |
| C. 今のまま(進むと書けば通る) | 何も足さない | 理由も止める時も残らない |

## 決めたこと

B。判断 `意思で進む(@名前)` と、引き受けた危なさ・止める線・期限・決めた人の表を足す。`pnpm bets` は残っているかだけを確かめ、期限を過ぎたら知らせる(止めない)。

## 結果として起きること

- 良くなること: 「なぜ出したのか」「いつやめるのか」が後から分かる。線を甘くして通す必要が無くなる
- 我慢すること: 止める線を守るのは人。キットは知らせるまで
- 見直す合図: 意思で進んだ賭けが、止める線の期限を過ぎても決めずに残り続ける(⏰ が溜まる)
