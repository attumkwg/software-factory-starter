# ADR 0025: 機能フラグと利用の記録は、外の製品を使わず自分の DB に持つ(定義はコード・組織ごとの状態と記録は RLS の表)

- 状態: 採用
- 日付: 2026-10-24
- 決めた人: @attumkwg(2026-10-24。設計書 0012 の U-1「切り替えは運営だけ」を承認。利用の記録の細部(人の ID まで持つ・400日で月1回手で消す)も同じ日に U-2・U-3 を承認)

## 背景

賭け(`docs/product/bets/`)の `rollout` は「一部の組織に出して、使われ続けるか」を確かめる段階。そのためには、

1. 組織ごとに機能を出す・止める(**機能フラグ**)
2. どの組織の・誰が・その機能を使ったかを数える(**利用の記録**)

が要る。どちらもキットに無かった。A/B テスト(くじで組に分けて比べる)はさらにその上に乗るが、PMF の前は組織の数が少なく差が偶然か分からないので、まず段階的な公開ができればよい。

このプロダクトはマルチテナント(組織ごと)で、テナントはセッションからだけ決め、全部の表に `tenant_id`+RLS(ADR 0001)。個人情報は分類表で管理し(ADR 0018)、ログは許可リスト(ADR 0019)。

## 選択肢

| 案 | 良い所 | 弱い所 |
|---|---|---|
| A. 外の機能フラグの製品(LaunchDarkly など)・外の分析の製品(Amplitude・Google Analytics など) | 画面がある・割合での公開や A/B の集計が最初からある | 月額の費用。組織の ID・人の ID を外に送る(委託先が増え、プライバシーポリシーと契約に書く物が増える)。RLS と監査ログの外に出る。PMF の前には機能が多すぎる |
| B. AWS の設定の置き場(AppConfig・Parameter Store)に組織の ID の一覧を置く | 費用が小さい・デプロイなしで変わる | 組織の ID の一覧を手で書く(書き間違い・解約で消し忘れ)。手元とテストに AWS の代わりが要る。利用の記録は別に要る |
| C. 環境変数・コードに組織の ID の一覧 | いちばん小さい | 出す組織を変えるたびにデプロイ。組織の ID がリポジトリに残る |
| D. **自分の DB**: 定義はコード(`@app/shared`)・組織ごとの「入れた」と利用の記録は `platform` の表(`tenant_id`+RLS)・切り替えと集計は運営のコマンド | 今ある決まり(RLS・解約の一覧・列の分類・監査ログ)にそのまま乗る。外に何も送らない。定義の名前は型で守れ、賭けとのつながりを CI で見られる。追加の費用が無い | 画面が無い(コマンドで切り替え・数を出す)。割合での公開・A/B の集計は自分で足す。すぐに全部で止めるのはデプロイ(数分) |

## 決めたこと

**D**。PMF の前に要るのは「選んだ組織に出す」と「使った組織と人を数える」だけで、どちらも今ある表の決まり(RLS・解約・分類・監査ログ)に乗せるのがいちばん安全で小さい。外の製品に組織と人の ID を送ると、委託先とプライバシーポリシーの見直しが先に要る。

- 定義(名前・賭け・説明・状態 `rollout` / `on` / `off`)は `packages/shared/src/feature-flags.ts`。
- 組織ごとの状態は `platform.feature_flags`(行がある = 入っている。アプリは読むだけ)。
- 利用の記録は `platform.feature_usage`(1日1人1機能1行。何をしたか・中身・時刻・URL・IP は持たない)。仕様 0012 の PR ②。
- 切り替え・集計・古い記録の削除は運営のコマンド(`node dist/cli.js …`)。お客さんの画面・API には出さない(仕様 0012 の未確定事項 U-1)。

## 結果として起きること

- 良くなること: 賭けの `rollout` の線(「出した組織の何割が使い続けるか」)を、デプロイせずに出す組織を変えながら測れる。フラグの消し忘れ(賭けをやめたのに残る)を CI が止める。
- 我慢すること: 画面が無い(運営がコマンドを打つ)。割合での公開・A/B の集計・デプロイなしの全部の停止は無い。利用の記録は「日」の単位で、細かい行動(どの順に押したか)は分からない。
- 見直す合図: 機能フラグが同時に10を超えた・運営以外(営業・サポート)が切り替えたくなった(→ 画面か A)。組織が数百を超えて A/B の差が測れる数になった(→ 割合での公開と A/B の集計を足す。`/bet` の A/B の型)。画面の細かい操作を見たくなった(→ 外の分析の製品。プライバシーポリシーと委託先の見直しが先)。
