# ADR 0086: AI のマージは使う人が選ぶ(既定はオフ・手元でもクラウドでも)

- 状態: 採用
- 日付: 2026-10-29
- 決めた人: @attumkwg(2026-10-29。会話で回答「AI は PR をマージしないというのは、保留にした方がいい。使う人による。まだ怖いと感じる人はマージしないようにしたいし、怖くないならマージしてほしいと感じるはず。今私はマージしてほしい」)
- ADR 0082 の「持ち主がクラウドの環境に入れた所だけ(手元は人がマージする)」を置き換える。マージの条件(1人の間・会話の答え・必須のチェックが全部緑・待つ間に push が無い)と ADR 0085 は変えない

## 背景

- ADR 0082 は、AI のマージを `pnpm pr:merge-when-green` だけにし、持ち主が**クラウドの環境**に `KIT_AI_MERGE=slack` を入れた所だけで動くとした。文書は「手元は人がマージする」と書いた。
- ところが、フック(`.claude/hooks/guard-bash.mjs`)とスクリプトが見ているのは「環境に変数があるか」だけで、手元かクラウドかは見ていない。文書と動きが食い違っていた。
- 持ち主は手元(デスクトップの Claude Code)で回すことが多く、2026-10-29 の #164〜#167 は、スイッチを通さずに `gh pr merge` でマージした(キットの外のセッションから回したので、キットのフックが効かなかった)。持ち主の言葉は PR に残したが、緑の確かめ・待つ間の push の確かめを飛ばした。
- 手元で入れられるなら、AI が手元の設定のファイル(`.claude/settings.local.json`・`~/.claude/settings.json`)に書いて、自分でスイッチを入れる道ができる。Bash はもともと `KIT_AI_MERGE` を含むコマンドを止めているが、Edit・Write は止めていなかった。

## 選択肢

| 案 | 良い所 | 弱い所 |
|---|---|---|
| A いつでも AI はマージしない | 一番固い | 守りを作ってきた人でも、毎回 GitHub を開いて押す |
| B 使う人が選ぶ(既定はオフ)。入れる所は手元でもクラウドでも。AI はスイッチを書けない | 怖い人はオフのまま・怖くない人はオン。どちらでも条件は同じ | 手元で入れた人は、手元の AI のマージを PR の記録で見る |
| C いつでもマージする | 速い | 怖いと感じる人に選ぶ道が無い |

## 決めたこと

**B**。

- AI のマージは**使う人が選ぶ**。既定はオフ(変数なし = 人がマージする)。オンにするのは、持ち主が自分で環境に `KIT_AI_MERGE=slack` を入れたときだけ。入れる所は、手元(`~/.claude/settings.json` か `.claude/settings.local.json` の `env`)でもクラウド(claude.ai/code の環境の変数)でもよい。
- オンでも、マージの道は `pnpm pr:merge-when-green` だけ。`gh pr merge`・`gh api … /merge` を直接打たない(フックが止める)。条件は ADR 0082・0085 のまま(1人の間・持ち主の会話の答え・必須のチェックが全部緑・待つ間に push が無い。答えの言葉と日時を PR に残す)。
- **AI はスイッチを自分で入れない**。編集のフック(`.claude/hooks/guard-edit.mjs`)が、設定のファイルに `KIT_AI_MERGE`・`KIT_EDIT_GUARD` を書く Edit・Write・MultiEdit を、いつでも止める(`KIT_EDIT_GUARD=pr` でも)。Bash はもとから `KIT_AI_MERGE` を含むコマンドを止める。
- 変数の値の名前 `slack` は変えない(入れている所が壊れないように)。
- 人が増えて承認の数を 1 以上にしたら、オンでも AI はマージしない(スクリプトが止める。今のまま)。

## 結果として起きること

- 良くなること: 使う人が「怖い / 怖くない」で選べる。手元でもクラウドでも、オンなら同じ確かめを通ってマージされる。AI がスイッチを自分で入れる道が塞がる。
- 我慢すること: 手元でオンにした人は、手元の AI のマージを、PR に残る持ち主の言葉と日時で後から見る。CI は会話の書き手を確かめない(ADR 0082 と同じ割り切り)。
- 見直す合図: 人が増えた(承認の数を 1 以上にする。Slack のボタン G-133)/ オンにした所で、持ち主が言っていないのにマージされた。
