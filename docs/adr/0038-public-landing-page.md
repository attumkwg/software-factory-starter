# ADR 0038: 公開の LP は、試作と分けてキットの中の静的な型を既定にし、事前登録は自前で受け、計測は外へ送らずに数える(提案)

- 状態: 提案(置き場所・計測は事業判断なので、人の答え待ち。設計書 0025 の U-1・U-2)
- 日付: 2026-10-25
- 決めた人: (未定。AI の仮決め)

## 背景

約束と売り文句が決まったら、記事・会のメール・広告から人を呼び、事前登録を集めたい(想定の場面の 8-3・8-6)。いまある試作の申し込みのページは、本物と混ぜない守り(ADR 0020)で **検索に載らない・計測を入れられない・外へ送らない**ので、人を呼ぶ LP に使えない。
LP は、キットで初めて **ログインしていない人の個人情報を集める所**で、Cookie で外へ送ると同意と公表の決まりがかかることがある。決めること: どこに置くか・どう測るか・事前登録をどこに残し、どう本物の組織につなぐか。仕様は `docs/specs/0025-public-landing-page.md`。

## 選択肢

置き場所:

| 案 | 良い所 | 弱い所 |
|---|---|---|
| **a. キットの中に静的な公開のページ `apps/site`(S3+CloudFront・本番は検索に載る)** | 約束・売り文句・トークンの正が1つのまま出る(AI が PR で直し、axe・VRT が見る)。事前登録が自前の DB に同意の版つきで残り、組織を作るコマンドにそのまま渡せる。月 0〜数十円 | 文の変更に PR とデプロイが要る。見たまま編集が無い。記事・ブログに向かない |
| b. 外の CMS で作り、キットは「言葉と色を写す段取り」と「事前登録を受ける所」だけ | 文を変えるのが速い・人が直せる。記事・ブログもそろう | 写し忘れで言葉と色がずれる。フォームの記録が CMS に残り、個人情報を CSV で人が運ぶ。委託先が1社増え、月額がかかる |
| c. 両方(a を持ちつつ b の道も支える) | どちらの会社にも合う | 持つ物が一番多い。キットの部品(`/tailor` で消せる)としては a と同じ |
| (外した)試作の申し込みのページを広げる | 新しい物が要らない | 試作の守り(偽のデータ・noindex・外へ送らない)を CI が強制しており、緩めると試作の約束が崩れる |
| (外した)`apps/web` に入れる | サーバーが増えない | `apps/web` は本番でも全部 noindex・ログインの後ろのサーバー(設計書 0015)。宣伝と守りのヘッダーが混ざる |

計測:

| 案 | 良い所 | 弱い所 |
|---|---|---|
| **自前で数える(Cookie なし・外へ送らない・日ごとの集計だけ)** | 同意の帯・外部送信の公表が要らない見込み。個人に結びつく物を持たない | 誰が見たかは分からない(広告の最適化に使えない)。数は目安 |
| 外の解析(Cookie で解析の会社へ送る) | 道具がそろう | 同意の帯・公表・委託先の台帳。法令の当てはめに専門家の確認が要る |
| 広告のタグ(コンバージョンを広告の会社へ送る) | 広告の最適化ができる | 上に加えて、個人関連情報の決まりがかかりうる。いちばん重い |

## 決めたこと(提案)

- 置き場所は **a**(人の答え待ち。設計書 0025 の U-1)。b の道は手引き(`docs/guides/landing-page.md`)の段取りで残す。
- 計測は **自前で数える** を既定にし、外の解析・広告のタグは入れると決めたときだけ(U-2)。
- 事前登録は **運営の組織の `tenant_id`** で自前の DB に持ち、確認のメール(ダブルオプトイン)を通った物だけを、組織を作るコマンド(G-01)の入力にする。同意の文の版とプライバシーポリシーの版を残す。
- どの案でも要る物(LP に要る物の一覧・同意の文の型・計測の同意の考え方・プライバシーポリシーに足すこと)は、答えを待たずに手引きに入れる。

## 結果として起きること

- 良くなること: 約束が決まったら、AI が LP の案を PR で出し、同じ色と部品で検索に載せられる。事前登録から組織を作るまでに、個人情報が人の手と外の道具を通らない。外へ送らないので、同意の帯が要らない。
- 我慢すること: 文の変更は PR を通す。記事・ブログは外の CMS。計測は「見た数・登録・確認・来た所」までで、広告の管理画面と数が合わない。
- 見直す合図: 広告に月数十万円をかけ始め、広告の最適化が要るようになった(→ 外の解析・タグと同意の帯)。文の変更が週に何度も要り、PR が重い(→ b か c)。記事で人を呼ぶのが主になった(→ CMS)。
