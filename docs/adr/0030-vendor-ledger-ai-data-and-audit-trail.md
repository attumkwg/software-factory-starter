# ADR 0030: 委託先は台帳を正にして CI で照らし、AI には ID と集計だけを渡し、AWS の管理操作は消せない記録に残す

- 状態: 提案
- 日付: 2026-10-25
- 決めた人: @attumkwg(AI-6 の決まり)。越境と prod のロックの強さは設計書 0017 の U-1・U-2 で確かめる

## 背景

P マーク・ISMS の準備で、最初に求められる3つが無かった。

1. **委託先の一覧と監督**(個人情報保護法 25条・ISMS 5.19〜5.22): どの会社に・何の区分の個人データを・どの国で預けているか。AI が SDK や AWS のサービスを足しても、誰も気づかない。
2. **AI に渡すデータの決まり**: 障害の一次調査を AI に頼む手順はあったが、何を貼ってよいかが無かった。AI の会社は米国にあり、委託先の監督と越境の両方の話になる。
3. **管理操作の記録の改ざん防止**(ISMS 8.15): AWS の操作の記録が既定(90日・消せる)のままで、事故の後に「誰が何をしたか」を出せない。

## 選択肢

**委託先の一覧**

| 案 | 良い所 | 弱い所 |
|---|---|---|
| A. 表計算・文書に人が書く | すぐ書ける | コードとずれても気づかない |
| B. 台帳(YAML)を正にして、CI でコード(SDK・Terraform・Actions)と照らす | 足した PR で必ず気づく。区分を列の分類表とそろえられる | SDK の名前の一覧に無い物・`fetch` で呼ぶ外の API は見つけられない |
| C. 全部の依存を台帳で分類させる | 漏れが無い | 外に出ない部品にも1行要り、続かない |

**AI に渡すデータ**

| 案 | 良い所 | 弱い所 |
|---|---|---|
| A. 個人データも、委託の契約の中で渡してよい | 調べ物が速い | 米国への越境・要配慮の扱いを毎回判断することになる |
| B. **ID と集計まで・要配慮は一切渡さない** | 越境と委託の範囲が小さくなる。貼る前に人が見る基準が単純 | 名前でしか再現しない不具合は、stg で再現してから渡す |

**管理操作の記録**

| 案 | 良い所 | 弱い所 |
|---|---|---|
| A. 組織のトレイル(全アカウントを1本で) | 新しいアカウントも自動で入る。2本目の費用が要らない | Organizations の管理アカウントを Terraform で持っていない |
| B. **アカウントごとのトレイル**(stg・prod)+組織へ移る手順書 | 今の Terraform の範囲で入れられる | dev・管理アカウントは入らない。アカウントが増えたら1つずつ |

## 決めたこと

- 委託先は **B**: `docs/compliance/vendors.yaml` を正にして、`pnpm vendors` が CI で照らす。AWS はサービスごとに区分を書く。区分は `classification.ts` から読む。台帳は危険度「高」。
- AI に渡すのは **B**(持ち主が決めた): `docs/security.md` の AI-6。台帳の AI の会社に personal・sensitive を書くと CI が落ちる。渡し方は `docs/compliance/ai-data.md`。越境の扱いは専門家に確かめる(設計書 0017 の U-1)。
- 管理操作の記録は **B**: `infra/terraform/modules/audit-trail` を stg・prod に。管理の出来事を全部・全リージョン・KMS で暗号化した S3(Object Lock・400日。prod は compliance)と CloudWatch Logs(90日)へ。root の利用と、記録を止める操作でアラーム。組織のトレイルへの移り方は `docs/runbooks/audit-trail.md` の 4。

## 結果として起きること

- 良くなること: 外の会社を足す PR で、預ける区分と国を必ず書く。AI に渡す物の基準が1つになる。AWS の操作が400日、消されずに残り、記録を止めると鳴る。
- 我慢すること: 名前の一覧に無い SDK・直接呼ぶ外の API は台帳の外になりうる(レビューで見る)。dev と管理アカウントの操作は、組織のトレイルに移るまで残らない。prod の記録は400日、消せない(費用は小さい)。
- 見直す合図: AWS のアカウントが3つを超えた・Organizations を Terraform で持った(→ 組織のトレイルへ)/ 外の会社が10社を超えた・認証の審査で委託先の評価の記録を求められた(→ 台帳に評価の欄)/ 越境について専門家の答えが出た(→ ai-data.md の 3 と台帳の `country`)
