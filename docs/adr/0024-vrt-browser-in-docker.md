# ADR 0024: 見た目の回帰テストは、ブラウザだけを Playwright の公式イメージの Docker で動かし、基準の画像はリポジトリに置く

- 状態: 採用(docs/designs/0011-visual-regression.md の U-1。2026-10-24 承認)
- 日付: 2026-10-24
- 決めた人: @attumkwg(PR で)

## 背景

画面の見た目を前と比べる仕組み(VRT)が無い([仕様 0011](../specs/0011-visual-regression.md))。
画像で比べるには、**同じ画面が、どの機械でも1画素も違わずに撮れる**ことが要る。文字の描き方(フォント・なめらかにする処理)は OS とブラウザの版で変わるので、作者の Windows と CI の Linux で撮ると、何も変えていなくても違いが出る。
あわせて、比べる元(基準の画像)をどこに置き、どう更新するかを決める必要があった。

## 選択肢

### どこで撮るか

| 案 | 良い所 | 弱い所 |
|---|---|---|
| A. 手元でもそのまま撮る(OS ごとに基準を持つ) | 道具が要らない | 基準が OS の数だけ要る。CI(Linux)の基準を手元で作れない |
| B. テストも丸ごと Docker の中で流す | 全部そろう | 手元の `node_modules`(Windows 用)をコンテナで使えず、コンテナの中で入れ直す仕組みが要る |
| C. **ブラウザだけを Docker の中で動かす**(`playwright run-server`)。テストの本体は手元・CI の Node | 描くのはいつも同じイメージの Chromium とフォント。テストの書き方・依存は今の E2E のまま。手元の画面(`localhost:8080`)には Playwright の `exposeNetwork` で届く | ブラウザとの間が WebSocket になる(少し遅い)。Playwright の版を3か所(`@playwright/test`・イメージ・起動のコマンド)でそろえる |
| D. 外のサービス(Chromatic・Percy など) | 差分の画面がきれい | お金がかかる。画面の画像を外に送る。キットの外に頼る |

### 基準の画像をどこに置くか

| 案 | 良い所 | 弱い所 |
|---|---|---|
| ア. **リポジトリ**(`apps/web/e2e/vrt/__screenshots__/`) | PR の差分で、前と後の画像を GitHub が並べて見せる。CI が何も取りに行かなくてよい。コメントにそのまま貼れる | リポジトリが重くなる(18 枚で約1.5MB。変えるたびに増える)。履歴から消しにくい |
| イ. main の CI の成果物 | リポジトリが重くならない | 成果物は期限で消える。取りに行く仕組みと権限が要る。PR の差分で見られない |
| ウ. 別のブランチや S3 | 重くならない | 書き込みの権限を PR の CI に渡す。仕組みが増える |

## 決めたこと

- **C**: ブラウザは `mcr.microsoft.com/playwright`(版とダイジェストを固定)の中の `playwright run-server`。`docker-compose.vrt.yml` で立てる。Mac(Apple の CPU)でも `linux/amd64` で動かし、CI と同じ画像にする。
- **ア**: 基準の画像はリポジトリに置く。写すのは種データだけ。画面を変えた PR は、基準の画像も一緒に変え、**人が PR の差分で前後の画像を見て判断する**。
- 基準は「変える」と明示したときだけ変わる: 手元の `pnpm vrt:update`、または PR のラベル `vrt:update`(CI が撮り直した基準を成果物にする。コミットは人か AI)。CI が自分で push しない(GitHub の鍵で push した commit では CI が動かず、確かめていない物がマージに回る)。

## 結果として起きること

- 良くなること: 部品の CSS を1行変えても、どの画面がどう変わったかが PR に出る。作者は手元で立ち上げなくても、PR のコメントで画面を見られる。
- 我慢すること: Playwright を上げるときは3か所を一緒に上げる(単体テストがずれを見張る。Renovate がまとめて上げる)。画面を変えるたびに基準の画像を撮り直してコミットする。リポジトリが少しずつ重くなる。
- 見直す合図: 基準の画像が 20MB を超えた・撮る画面が 50 を超えた(→ 案イか Git LFS)/ Chromium 以外の見た目も比べたくなった(→ 同じイメージの Firefox・WebKit)/ 揺れ(何も変えていないのに落ちる)が月に2回を超えた(→ 揺れる所を塗る・許す画素を増やす)。
