# ADR 0020: 確かめるための試作は、dev アカウントの S3+CloudFront に合言葉つきで置く

- 状態: 採用
- 日付: 2026-10-22
- 決めた人: @attumkwg(置き場所は本人の選択 2026-10-22。作りは docs/guides/prototypes.md)

## 背景

`before-pmf.md` の ②(解決策)・③(お金)は「画面だけ」「申し込みのページ」で確かめると書いてあるが、出し方の型が無かった。毎回、作り方・置き場所・守り(本物と混ぜない・検索に載せない・後で消す)を考え直すことになり、「確かめながら作る」が遅くなる。キットは公開リポジトリとして配るので、置き場所は使う人の AWS か無料の物で、誰でも見られる所には置けない。

## 選択肢

| 案 | 良い所 | 弱い所 |
|---|---|---|
| A. AWS の dev アカウントに S3(非公開)+CloudFront(OAC)+CloudFront Functions の合言葉 | キットの OIDC・dev アカウント・Terraform にそのまま乗る。NAT・ALB が要らず 月 0〜数十円 | AWS が要る。合言葉は Basic 認証なので、1人ずつの記録は取れない |
| B. Cloudflare Pages+Access | 無料枠で人数を絞れる(メールで1人ずつ)。AWS が無くても出せる | 別のサービスのアカウントと秘密が増える。キットの Terraform と CI の外になる |
| C. GitHub Pages | 設定がほぼ要らない | 公開のリポジトリだと**誰でも見られる**。試作には向かない |
| D. プレビュー環境(ECS)に載せる | 本物と同じ仕組み | 土台だけで 月 約1.2万円。試作に API・DB は要らない |

## 決めたこと

**A**(本人の選択)。AWS が無い人には、手元の `pnpm prototype:dev <賭けの ID>` を画面共有で見せる道を残す。

- 置き場所は `envs/preview/prototypes`(dev アカウント)。プレビューの土台とは別に立てられる。
- 合言葉は CloudFront の KeyValueStore に人が CLI で入れる(Terraform の変数にしない = 状態のファイルにも残さない)。鍵が無ければ誰も通さない。全部で通る `_all` と、試作ごとの `B-NNNN` の2種類。
- GitHub Actions の役割は、試作のバケットの `B-*` の下に置く・消すだけ。ビルド(PR のコードが動く)は AWS の権限の無いジョブで行い、置くジョブはビルドの結果を写すだけ。
- 検索に載せない: `index.html` の meta と、CloudFront の応答ヘッダー `X-Robots-Tag: noindex, nofollow`。
- 本物と混ぜない: Biome の `noRestrictedImports` と `pnpm prototypes`(依存・相対パス・`.env`・noindex・賭けのファイル)。Semgrep(危険度「高」の場所)には足さない。

## 結果として起きること

- 良くなること: 賭けの `psf` で、画面を作って URL を渡すまでが PR 1本で済む。費用はほぼ0円。閉じた賭けの試作は、フォルダを消せば置き場所からも消える。
- 我慢すること: 合言葉は1人ずつではない(誰が開いたかは分からない)。合言葉を渡した人がさらに渡せる。だから**偽のデータだけを置く**ことを本当の守りにする。WAF・アクセスログは付けない。
- 見直す合図: 本物に近いデータを見せたくなった・相手ごとに見られる人を絞りたくなった(→ B か、本物のアプリの中で機能フラグ)・試作を開く人が月に数万を超えた(費用を見直す)。
