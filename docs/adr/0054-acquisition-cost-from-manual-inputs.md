# ADR 0054: 届け方は機能と同じ賭けで確かめ、獲得のコストは手入力で費用のページに出す

- 状態: 提案
- 日付: 2026-10-25
- 決めた人: @attumkwg(提案は AI。承認待ち)

## 背景

どの届け方(展示会・記事・紹介・広告)が効いたか・1社を取るのにいくらかを測りたい(仕様 0043・穴 G-36)。決めることは2つ: ① 届け方を確かめる型をどう持つか ② 広告費と営業の時間をどこから取るか。

## 選択肢

① 届け方を確かめる型

| 案 | 良い所 | 弱い所 |
|---|---|---|
| A. 届け方専用の台帳(新しいフォルダ・新しい段階・新しい検査) | 届け方に合った段階にできる | 検査・ロードマップ・会計区分の案を別に作る。賭けの考え方が2つになる |
| B. 機能の賭けと同じファイル・段階・検査で、ひな形と段階の読み替えだけ足す | 今の `/bet`・`pnpm bets`・ロードマップがそのまま使える | 段階の名前(cpf・psf)が届け方には少し合わない(ひな形と手引きで読み替える) |

② 広告費と営業の時間

| 案 | 良い所 | 弱い所 |
|---|---|---|
| A. 広告の画面・CRM の API から自動で取る | 書き忘れが無い | 外の会社の鍵を GitHub に置く。道具ごとに作り直し |
| B. 月に1回、人が届け方ごとに手で書き、非公開の置き場に置く | 道具を選ばない。今の手入力(時給・時間・売上)と同じ流れ | 書き忘れる(無ければページに足りない物として出す) |

## 決めたこと

① は **B**、② は **B**。費用のページは直近3か月を届け方ごとに足し、「1社を取るのにいくら」を出す。営業の時間は時給の既定で円にする。獲得が5組織未満の届け方に印。個社・人ごとは持たない。

## 結果として起きること

- 良くなること: 届け方も「線を先に決めて確かめる」になる。1社を取る額が数で見える。外の鍵が増えない。
- 我慢すること: 手で書く。どの組織がどの届け方から来たかは分からない(届け方ごとの継続は話を聞く)。
- 見直す合図: 届け方が多くなり手で書くのが重い(CRM を入れたら自動の取り込みを考える)・届け方の賭けの段階の読み替えで迷う人が多い。
