# ADR 0016: アカウントを変える前にパスワードを確かめ直し、そこで得た Cognito のアクセストークンは暗号化した短い Cookie で持つ

- 状態: 採用(docs/designs/0006-account-security.md の U-1。2026-10-20 承認)
- 日付: 2026-10-20
- 決めた人: @attumkwg(AI の案を承認)

## 背景

二段階認証の設定・メールアドレスの変更・パスワードの変更(docs/specs/0006-account-security.md)は、Cognito の「本人の操作」の API(`AssociateSoftwareToken`・`VerifySoftwareToken`・`SetUserMFAPreference`・`ChangePassword`・`UpdateUserAttributes`・`VerifyUserAttribute`)を呼ぶ。これらは**その人のアクセストークン**が要る。`AssociateSoftwareToken` には管理者版(`Admin*`)が無い。

いまの作りでは、ログインのときに ID トークンを確かめたらすぐ捨て、セッションは自前の署名つき Cookie にしている(ADR 0007「トークンはサーバーの中だけ」)。アクセストークンはどこにも無い。

また、盗まれた Cookie だけでメールアドレスを変えたり二段階認証を外したりできると、乗っ取りが固まる。変える前にパスワード(と二段階認証のコード)を確かめ直したい。確かめ直すと、Cognito から新しいアクセストークン(15分)が返る。

二段階認証の設定(鍵を出す → コードを入れる)とメールアドレスの変更(申し込む → 確認コードを入れる)は、**2回のリクエストに分かれ、その間もアクセストークンが要る**。

## 選択肢

| 案 | 良い所 | 弱い所 |
|---|---|---|
| A. 暗号化した HttpOnly Cookie(AES-256-GCM・10分・SameSite=Strict)に入れる | 表が増えない。いまの「ログインの途中の札」(`pending-mfa.ts`)と同じ形。JS からは読めず、鍵が無ければ中身も見えない | トークンがブラウザまで行く(暗号化されてはいる)。ADR 0007 の例外になる |
| B. DB に10分だけ持つ(暗号化して。Cookie には ID だけ) | トークンはサーバーの中だけのまま | 表・RLS・解約で消す一覧・期限切れの掃除が増える。DB の写し(バックアップ)にもトークンが残る |
| C. 持たない(2回目のリクエストでもパスワードを入れ直してもらう) | 何も持たない | 利用者は同じ操作の中でパスワードを2回入れる。二段階認証が有効な人はコードも2回 |
| D. 管理者版の API(IAM)を使う | トークンが要らない(鍵を作る所を除く) | 鍵を作る API に管理者版が無いので成り立たない。API の鍵1本で誰のアカウントでも変えられる形になる |

## 決めたこと

**A**(作者 @attumkwg の承認)。

- Cookie `__Host-reauth`(手元は `reauth`)・HttpOnly・Secure・SameSite=Strict・Path=/・10分。
- 中身 `{ userId, accessToken, exp, failures }` を AES-256-GCM で暗号化。鍵は `HKDF-SHA256(SESSION_SECRET, info="reauth-v1")`(セッションの署名とは別の鍵)。
- 使うときに、セッションの本人と `userId` が同じかを確かめる。違う・壊れている・切れているなら「札が無い」。
- 変更を1回終えたら、`GlobalSignOut` でアクセストークンを無効にし、Cookie を消す。
- パスワードの変更と二段階認証を外す操作は、1回のリクエストで終わるので札を使わない(API の中だけでトークンを使って捨てる)。

## 結果として起きること

- 良くなること: 盗まれた Cookie だけでは、アカウントの大事な所を変えられない。表を増やさずに Cognito の本人の操作が使える。
- 我慢すること: アクセストークン(暗号化済み)が最長10分ブラウザにある。`SESSION_SECRET` が漏れると、札の中身も読める(そのときはセッションも偽造できるので、守りの強さは変わらない)。
- 見直す合図: サーバー側のセッション保存(DB か Valkey)を作ったら、B に移す。Cognito がアクセストークン無しで鍵を作れるようになったら、D を見直す。
