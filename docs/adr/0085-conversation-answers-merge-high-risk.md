# ADR 0085: 1人の間は、会話の答えを PR に残して、危険度「高」も工場がマージする

- 状態: 採用
- 日付: 2026-10-29
- 決めた人: @attumkwg(2026-10-29。会話で回答「全部アグリー」。仕様 0085 の「決めたこと」)
- ADR 0082 の「見直し(2026-10-28)」を、1人の間だけ置き換える

## 背景

- ADR 0082 の見直し(#152)で、危険度「高」・テストを弱めた印・守りの場所に触る PR は AI がマージせず、「人が GitHub で中身を見て押す」にした。
- 1人の間は、レビューする人も答える人も持ち主1人。持ち主はチャットか Slack で答えており、GitHub を開いて押すのは手間だけが増える。#159・#160 は、会話の承認の言葉を PR にコメントで残してマージした(手で1回)。
- 持ち主の原則: 人が見るのはセンサーが正しいかの判定と、決めなければならない所への端的な答えだけ(ロードマップの 6)。

## 選択肢

| 案 | 良い所 | 弱い所 |
|---|---|---|
| A 今のまま(高は人が GitHub で押す) | 人が中身を開く | 会話で答えても GitHub を開く。人の出番が減らない |
| B 1人の間だけ、会話の答えを PR に残して高もマージ。人が増えたら Slack の署名つきのボタン | 答えは人がいる場所で終わる。記録が PR に残る | CI は会話の書き手を確かめない(0082 と同じ割り切り) |
| C いつでも B | 人が増えても速い | 2人目の目を外す |

## 決めたこと

**B**。1人の間(`.github/setup.yml` の `required_approvals: 0`)だけ:

- `pnpm pr:merge-when-green <番号> --reply "<持ち主の言葉>" --answered-at <答えた日時>` は、危険度「高」・テストを弱めた印・守りの場所に触る PR も断らない。
- マージの前に、持ち主の言葉そのまま・答えた日時(日本時間)・当てた版・人の答えが要った理由・触った「高」の領域の問い([../concepts/risk-areas.md](../concepts/risk-areas.md))を PR にコメントで残す(「## 持ち主の承認(会話で…」)。
- 危険度「高」の PR では、AI は先に領域の問い(1問1行・選択肢つき・多くて2問)を会話で聞き、答えを得てからマージに進む(`/slack-request`)。
- 本番に出す承認(GitHub の環境 prod)は会話で代えない。

人が増えたら(承認数が 1 以上)AI のマージは止まり、答えは押した人を確かめられる Slack のボタンで受ける(G-133。まだ作っていない)。

## 結果として起きること

- 良くなること: 危険度「高」でも、会話で答えれば工場がマージまで進める。PR に答えの記録が残り、判断待ちの積み場はそれで答え済みと見る。
- 我慢すること: CI は会話の書き手を確かめない。AI が答えを偽った場合、気づくのは PR の記録と会話を後で読んだとき。守りの場所(マージのスクリプトそのもの)を変える PR も会話の答えで入る。
- 見直す合図: 人が増えて承認数を 1 以上にしたとき(自動で止まる)・答えの記録と会話が食い違ったことが1度でもあったとき・本番で事故が出たとき。
