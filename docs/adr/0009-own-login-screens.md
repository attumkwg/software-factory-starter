# ADR 0009: ログインの画面は自前で作り、API が Cognito の API を呼ぶ(偽物は契約テストで本物と比べる)

- 状態: 採用(ADR 0007 の「3. ログインの画面」を置き換え)
- 日付: 2026-10-18
- 決めた人: @attumkwg

## 背景

ADR 0007 では、ログインの画面を Cognito の画面(Managed Login)にした。だが、デザインシステムを作っている以上、それに合わない見た目が入り込む(作者「自作せずは難しい」)。

画面を自作すると、偽物の Cognito も「Cognito の API」(登録・確認コード・ログイン・二段階認証・再設定)を話す必要があり、重くなる。偽物が本物とずれていけば、手元で通っても本番で壊れる。作者「実運用の際に Cognito の現状を確かめて、再チェックする仕組みを」。

## 選択肢

| 案 | 良い所 | 弱い所 |
|---|---|---|
| A. 画面 → API → Cognito の API(USER_PASSWORD_AUTH) | トークンは API の中だけのまま。見た目はデザインシステム | パスワードが API を通る(ログに出さない決まりとテストが要る) |
| B. 画面(ブラウザ)→ Cognito の API(SRP) | パスワードがこちらのサーバーを通らない | トークンがブラウザに出る(ADR 0007 の「トークンはサーバーで閉じる」に反する) |

偽物の確かめ方:

| 案 | 良い所 | 弱い所 |
|---|---|---|
| A. 契約テスト(同じテストを偽物と stg の本物に流す) | ずれたら自動で分かる(週1回・Issue)。AWS 公式の SDK でつなぐので、偽物が本物の取り決めを話せることも確かめられる | stg に試しの人を作る権限が要る |
| B. 偽物を作り込むだけ | 部品が少ない | ずれに気づけない |

## 決めたこと

**どちらも A**(作者 @attumkwg の選択)。

- 画面: ログイン(パスワード → 二段階認証のコード / 確認がまだなら確認コード)・登録(→ 確認コード)・パスワードの再設定。二段階認証の設定とメールアドレスの変更は次の PR。
- API: `POST /api/auth/{login,mfa,sign-up,confirm-sign-up,resend-code,forgot-password,reset-password}`。Cognito の API は SDK を使わず fetch で呼ぶ(JSON 1.1)。
  - 「その人はいない」と言わない: ログインの失敗は全部同じ 401 と同じ文。登録・コードの再送・再設定は、いない人・登録済みの人にも同じ答え。
  - 二段階認証の途中の札(Cognito の Session)は署名つきの HttpOnly Cookie(3分・SameSite=Strict)。間違えたらパスワードから(札は1回きり。本物も同じかは契約テストが確かめる)。
  - パスワード・確認コード・トークンはログに出さない(結合テストが確かめる)。
- ADR 0007 の「Cognito の画面へ移る流れ」(`/api/auth/login`・`/callback`)と、ZAP のスキャン用のクライアントは消した。ZAP も画面と同じ `POST /api/auth/login` でログインする。
- 設定の正は `packages/shared/src/cognito-settings.json`(パスワードの決まり・確認コードのメールの文面)。Terraform・偽物・画面が同じ物を読む。
- 偽物(`packages/fake-cognito`)は、アプリが使う入口と、契約テストが使う管理の入口だけ。契約テスト(`packages/fake-cognito/contract`)を、偽物には PR ごとに、stg の本物には週1回(`cognito-contract.yml`)流す。本物で落ちたら Issue。

## 結果として起きること

- 良くなること: 見た目がデザインシステムでそろう。手元で、登録の確認コードのメールまで本物と同じ道(Postfix → Mailpit)で試せる。偽物のずれに自動で気づける。
- 我慢すること: パスワードが API を通る(TLS の中・ログに出さない)。偽物を保つ手間(契約テストが落ちたら直す)。Cognito のユーザープールは Lite(パスキー・メールでの二段階認証は使えない)。
- 次にやること: 二段階認証の設定の画面(QR コード)・メールアドレスの変更・パスワードの変更。管理者の二段階認証の必須化。
- 見直す合図: 契約テストが本物で落ちる。パスキーが要る(Essentials に上げ、ブラウザと Cognito のやり取りを足す)。
