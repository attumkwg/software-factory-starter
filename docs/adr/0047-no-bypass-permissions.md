# ADR 0047: このリポジトリでは、Claude Code の確認を飛ばすモードを使わない

- 状態: 採用
- 日付: 2026-10-25
- 決めた人: @attumkwg(穴を埋める順番と TODO の解消を会話で指示。設定の中身は AI が決めた)

## 背景

乗っ取られた依存が、開発者の端末に入っている AI の CLI を確認を飛ばす旗で呼び、鍵を探させた攻撃があった。キットは危険度「高」の編集と Bash を確認で止めているが、確認を飛ばすモードではそれが効かない。

## 選択肢

| 案 | 良い所 | 弱い所 |
|---|---|---|
| A. リポジトリの設定で禁止 | このフォルダの中では確実に止まる・全員に同じ | リポジトリの外で呼ばれる分は止まらない |
| B. 手引きに「使わない」と書くだけ | 何も変えない | お願いでは止まらない |
| C. 端末に配る設定だけ | 外でも止まる | 端末の管理が要る(1〜10人では重い) |

## 決めたこと

A。加えて、人が増えたら C を足す考え方を `docs/guides/local-guards.md` に書く。

## 結果として起きること

- 良くなること: 乗っ取られた依存がこのフォルダで AI の CLI を呼んでも、確認が出る
- 我慢すること: 確認が多いと感じる人は、`KIT_EDIT_GUARD=pr` で危険度「高」の編集の確認だけを外す(PR の段で人が見る)
- 見直す合図: Claude Code の設定の名前や働きが変わったとき(点検の `/checkup-refresh`)
