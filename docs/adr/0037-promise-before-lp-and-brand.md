# ADR 0037: 約束(言葉)を先に決め、LP とブランド(名前・トーン・色)はその後に、約束から作る

- 状態: 提案
- 日付: 2026-10-25
- 決めた人: @attumkwg(提案は AI。承認待ち)

## 背景

- 2026-10-25 に、最高の想定の A 社で企画から売り始めまで通しで回したら、作って出すまでは回るが「売る前」でつまずいた。売り文句が決まらないまま、LP の見出しとプロダクトの色を別々に決めることになった(想定の場面の 8-1・8-2)。
- 持ち主の言葉:「何を決めるかが無いと、LP もプロダクトと合わない物になり、プロダクトのカラーも決まらない」「フィットジャーニーと密接に絡む」。
- 約束の材料(相手の言葉・何が効いたか・代わりの物)は、キットの中にもう溜まっている(`docs/product/interviews/`・賭けの小石・`plan.md`)。
- デザインシステムの決まりでは、トークン(色)を決めるのは人で、AI は案を出しコントラストを計算する(`docs/design-system.md`)。

## 選択肢

| 案 | 良い所 | 弱い所 |
|---|---|---|
| A. 約束 → LP → ブランドの順に段を足す(約束は `/positioning`、ブランドはその後の段) | LP・色・営業の言葉が1行の約束にそろう。材料がキットの中にある | 段が1つ増える。PSF の前は約束が仮になる |
| B. ブランドと LP を同時に決める(デザインの会社に任せる形) | 早い。見た目から入れる | 約束と合わない色・言葉になりやすい。キットの材料が使われない |
| C. 段を足さず、手引きに順番だけ書く | 足す物が少ない | 通しの試しで、材料から言葉をつなぐ手順が無くて止まった(いまと同じ) |

## 決めたこと

A。決める順番は**言葉 → LP → 色**(`docs/scenarios/fit-journey.md` の 2)。

- 約束・売り文句・代わりとの違い・言わないことは `/positioning` が材料から案を出し、人が選んで `docs/product/positioning.md` に残す(仕様 0023)。
- ブランド(名前・トーン・色)は、約束と相手(業種・使う場所)から案を出し、色は `packages/ui/src/tokens.css` を置き換える PR にする(仕様 0024)。**約束が無いときはブランドを始めない**(仮の約束でよい)。
- フィットジャーニーの線は目安。PSF の前でも止めず、仮で進んだことを「これまでの判断」に `意思で進む(@名前)` の形で残す。

## 結果として起きること

- 良くなること: LP・チラシ・営業の資料・画面の色が同じ約束から作られる。約束を変えたときに、どこを直すか(下流)が分かる。
- 我慢すること: 色や名前を先に決めたい人(デザイナー・営業)も、約束(仮でよい)を待つ。
- 見直す合図: 約束が決まる前にブランドを決める必要が、使う人の場面で2回出たら(例: 資金調達の資料の締め切り)。
