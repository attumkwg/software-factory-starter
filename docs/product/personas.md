## P-1 進み具合を見て、催促する人

- 立場: 使う人
- 決める力: 影響
- 根拠: 推測(架空。B-0002 の cpf で5組織中4つが「毎朝探している」と話した、という設定)
- 役割と状況: 現場監督・制作進行。現場を3〜5件持つ。朝は事務所のパソコンで一覧を見て、日中は外からスマホで確かめる
- やりたいこと(用事): 期限に遅れそうな仕事を早めに見つけ、誰に声をかけるかを決める
- 成功の物差し(数で): 催促の電話・チャットが週5回 → 1回。毎朝の確認が15分 → 2分
- 制約: 日中は運転と現場で、画面を見られるのは合間の数分
- 困りごと: 「終わったかは画面を開かないと分からない」「期限が近いのを毎朝探している」
- 断る理由(よく出る反論): 「みんなが入力してくれないと意味がない」「通知が増えると見なくなる」
- 何があれば変わるか: 自分が何も探さなくても、遅れそうな物だけが朝に届く
- いまの代わり: Excel の表と、チャットで「終わりましたか?」
- 話し方(記録の言葉): (架空のため無し)

## P-2 タスクを片づける人

- 立場: 使う人
- 決める力: なし
- 根拠: 推測(架空)
- 役割と状況: 職人・作業者。現場でスマホ。手が空いたときに少しだけ見る
- やりたいこと(用事): 自分の分を終えて、終わったことを伝える
- 成功の物差し(数で): 「終わりました」を伝える手間が電話1回 → タップ1回。終わった後に聞かれる回数が週3回 → 0回
- 制約: 手袋・汚れた手・電波が弱い。文字を打つのは嫌い
- 困りごと: 「終わったのに、また電話で聞かれる」
- 断る理由(よく出る反論): 「入力は事務の仕事」「アプリを開くのが面倒」
- 何があれば変わるか: 1回押すだけで済み、それで電話が来なくなる
- いまの代わり: 電話・チャットで「終わりました」
- 話し方(記録の言葉): (架空のため無し)

## P-4 お金を出す社長

- 立場: 買う人
- 決める力: 予算
- 根拠: 推測(架空)
- 役割と状況: 10〜30人の会社の社長。現場も見るが、月末は資金繰りと請求
- やりたいこと(用事): 遅れ・やり直しで失う売上と、人の残業を減らす
- 成功の物差し(数で): 工期の遅れによる値引き・やり直しが月 N 件 → 0件。月の費用が1人あたり数百円まで
- 制約: 月の固定費を増やしたくない。年契約は嫌う
- 困りごと: 「どこが遅れているかを知るのが、いつも事後」
- 断る理由(よく出る反論): 「前に入れた道具も結局使われなかった」「人数で値段が上がるのは困る」
- 何があれば変わるか: 1か月で現場が使っているのが数で見える・やめやすい
- いまの代わり: 朝礼と現場監督からの口頭の報告
- 話し方(記録の言葉): (架空のため無し)

## P-5 導入を進める事務の長

- 立場: 決める人
- 決める力: 影響
- 根拠: 推測(架空)
- 役割と状況: 総務・事務の長。道具の比べと申し込み・アカウントの配布・使い方の説明をする
- やりたいこと(用事): 現場に負担をかけずに入れ、問い合わせが自分に集まらないようにする
- 成功の物差し(数で): 入れてから全員が使い始めるまで2週間以内。自分への「使い方が分からない」が週1回以下
- 制約: 説明会を開く時間が無い。ほかの道具(会計・勤怠)と二重入力にしたくない
- 困りごと: 「入れるたびに、使い方の質問が全部自分に来る」
- 断る理由(よく出る反論): 「また ID とパスワードが増える」「説明する時間が無い」
- 何があれば変わるか: 招待のリンクを送るだけで、現場が自分で始められる
- いまの代わり: Excel のひな形を配る
- 話し方(記録の言葉): (架空のため無し)

## P-6 アカウントと安全を見る外部の IT 担当

- 立場: 止める人
- 決める力: 拒否権
- 根拠: 推測(架空)
- 役割と状況: 外部に頼んでいる IT の担当(月に数時間)。パソコン・アカウント・情報の持ち出しを見る
- やりたいこと(用事): 辞めた人のアカウントを確実に止め、取引先の情報を外に出さない
- 成功の物差し(数で): 辞めた人のアカウントが残っている日数 0日。取引先から聞かれる安全の質問に答えられない項目 0
- 制約: 時間が少ない。新しい道具ごとに確かめる余裕が無い
- 困りごと: 「現場が勝手に入れた道具に、辞めた人のアカウントが残る」
- 断る理由(よく出る反論): 「二段階認証が無い・人を止められない道具は入れられない」「データがどこに置かれるか分からない」
- 何があれば変わるか: 管理者が自分で人を止められる・ログイン履歴が見える・置き場所が国内
- いまの代わり: 道具ごとに手で確かめる(漏れる)
- 話し方(記録の言葉): (架空のため無し)

## P-7 支払いを止められる経理

- 立場: 止める人
- 決める力: 拒否権
- 根拠: 推測(架空)
- 役割と状況: 経理の担当。カードの明細・請求書・インボイスを見る
- やりたいこと(用事): 何にいくら払っているかを毎月説明でき、使っていない物を止める
- 成功の物差し(数で): 説明できない支払い 0件。請求書の受け取りから処理まで1日
- 制約: 請求書はインボイスの形で要る。カード払いは社長の承認が要る
- 困りごと: 「使っているか分からないサービスの請求が毎月来る」
- 断る理由(よく出る反論): 「請求書が出ない・人数が月ごとに変わって説明できない物は払えない」
- 何があれば変わるか: 月の人数と金額が決まった日に分かる・請求書が自動で来る
- いまの代わり: カードの明細を見て、社長に聞く
- 話し方(記録の言葉): (架空のため無し)

## P-9 今の Excel の表を作っている事務の人

- 立場: 失う人
- 決める力: 影響
- 根拠: 推測(架空)
- 役割と状況: 進み具合の Excel の表を毎日更新し、社長と監督に配っている。社内で「表の人」として頼られている
- やりたいこと(用事): 表を正しく保ち、聞かれたらすぐ答える
- 成功の物差し(数で): 表の更新にかける時間が1日1時間 → 0分。それでも頼られる役目があること
- 制約: 新しい道具を覚える時間は昼休みの後だけ

- 何があれば変わるか: 自分が表の代わりに「まとめを配る人」になれる・印刷できる

## P-10 問い合わせを受ける自社の CS

- 立場: 運営
- 決める力: 影響
- 根拠: 推測(架空)

- やりたいこと(用事): 少ない人数で、困っているお客さんに早く気づき、やめられる前に手を打つ
- 成功の物差し(数で): 1社あたりの問い合わせが月2件以下。使い始めて4週後に使い続けている組織の割合

- 断る理由(よく出る反論): 「機能を増やすほど問い合わせが増える」
- 何があれば変わるか: 使われなくなりそうな組織が、数で早めに分かる
- いまの代わり: 解約の連絡を待つ
