# 障害の振り返り(記録)

S1・S2 の障害の振り返りを、1件1ファイルで置く(`YYYY-MM-DD-<短い名前>.md`)。書き方と形は [runbooks/incident.md](../runbooks/incident.md) の 6。

- **記録なので、書いた後は直さない**(後で分かったことは、新しいファイルか追記の節で)。
- **個人データが絡むときは、振り返りを待たずに知った時点でファイルを作り**、「個人データの漏えい等」の欄(知った日時・判定・速報と確報の期限と出した日)を埋めていく。報告の期限を数えるため([runbooks/personal-data-breach.md](../runbooks/personal-data-breach.md))。
- 人の名前を主語にしない。お客さんの名前・個人情報・秘密を書かない。
- 再発防止の Issue が全部閉じたかを、毎月の点検で見る。
