# 型: 見積書

> ⚠️ 文面(法律の文)は書かない。**項目・キットの既定・根拠・使う人が決めること**だけ([README.md](README.md) と同じ形)。金額はキットに無い(会計ソフト・価格表の金額の置き場)。
> 見積 → 申込 → 開通の流れは [guides/sales.md](../guides/sales.md) の 2。

## 1. 欄の一覧

| 欄 | キットの既定 | 根拠(どのファイル) | 使う人が決めること |
|---|---|---|---|
| 宛先の会社 | 会社の正式な名前(申込書と同じ書き方) | [order-form.md](order-form.md) の「申し込む会社」 | 部署・担当者の名前まで書くか |
| プラン | プランの名前(`@app/shared` の `PLANS` の id と画面に出る名前) | [specs/0047-plans.md](../specs/0047-plans.md) | プランの名前と中身 |
| 価格表の版 | `PRICE_LISTS` の id(どの版の金額か)。**申込書・申し込みの JSON と同じ版**にする | [runbooks/plans.md](../runbooks/plans.md) の 3 | 金額(会計ソフト) |
| 人数 | 契約の人数(申込書の「人数」・JSON の `seats`) | [order-form.md](order-form.md) の「人数」 | 超えたときの扱いを見積に書くか |
| 期間 | 申込書の「契約の期間」と同じ(既定 1年) | [order-form.md](order-form.md) | 月ごとか・1年か |
| 有効期限 | 出した日から **30日**(案) | — | 何日にするか・過ぎたら出し直すか |
| 据え置き | あれば期限の日(JSON の `priceLockedUntil`) | [runbooks/plans.md](../runbooks/plans.md) の 3 | 据え置きを付ける条件 |
| 初期費用・導入の手伝い | 欄だけ置く(キットは数えない) | — | 付けるか・何をするか |
| 付けるもの | SLA・個人データの取り扱いの取り決めを付けるか | [sla.md](sla.md)・[data-processing.md](data-processing.md) | どのプランに付けるか |

## 2. してはいけない

- 見積をリポジトリに置く(お客さんの名前・金額)。
- 申込書と違う価格表の版で開通する(値上げのときに据え置きの対象が分からなくなる)。
