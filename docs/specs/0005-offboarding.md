# 仕様: 解約(データの書き出しと削除)

> 状態: 承認済み(承認した人: @attumkwg。2026-10-18 の選択「書き出しは画面から・削除は運営が手順書とコマンドで」)

## なぜ作るか

解約するお客さんは「自分のデータを持って出られる」「出たあと消してもらえる」ことを求める(契約・個人情報の法律)。書き出しが無いと乗り換えの妨げになり、削除の手順が無いと「消したつもり」で残る。docs/security.md の T-9「解約時のデータの書き出しと削除(バックアップの保存期間も含めて)を手順にし、契約書と合わせる」。

## 受け入れ条件

書き出し(お客さんの管理者が、いつでも):

- [ ] 管理者は画面「設定」の「データの書き出し」で、自社のデータを1つの JSON ファイルで受け取れる
- [ ] 中身: 組織・利用者(名前・メール・ロール)・プロジェクト・タスク・監査ログ・サポートへの許可(番号は入らない)
- [ ] 入らない物: 認証の製品の ID(Cognito の sub)・番号のハッシュ・送信待ち(アウトボックス)・**他社の物**
- [ ] 書き出したことが監査ログに残る(誰が・いつ)
- [ ] メンバー・閲覧者・代理の社員は書き出せない(403)

削除(運営が、契約を確かめてから):

- [ ] 運営はコマンド `delete-tenant <組織の ID>` で、まず**試し**(何をいくつ消すかを出すだけ。消さない)を流せる
- [ ] 本当に消すのは `--execute --confirm-name <組織の名前>` を付けたときだけ(名前が違えば何もしない)
- [ ] 消すのは、その組織の全部の表の行(新しい表を足したのに、消す一覧に足していなければ CI が落ちる)。ほかの組織の行には触れない
- [ ] 1つのトランザクションで消す(途中で失敗したら、何も消えていない)
- [ ] 監査ログも消す(組織と一緒に)。そのかわり、**運営の組織の監査ログ**に「いつ・どの組織 ID を・何件消したか」を残す(名前・中身は残さない)
- [ ] 運営の組織そのものは消せない
- [ ] 消した後に残る所(バックアップ・ログ・Sentry・Cognito)と、いつ消えるかを、手順書と契約の資料に書く

## 権限の表に足す行

| API | admin | member | viewer | 他社 | 未ログイン |
|---|---|---|---|---|---|
| `POST /api/exports` | 200 | 403 | 403 | — | 401 |

削除はコマンドだけ(API は作らない。戻せない操作を、画面や API の鍵1本でできないようにする)。

## 悪用のされ方(STRIDE で1行ずつ)

| 観点 | どう悪用されうるか | どう防ぐか(テスト / ルール) |
|---|---|---|
| なりすまし | 管理者になりすまして、全データを持ち出す | ふつうのログイン+管理者だけ。書き出しは監査ログに残る(お客さんが気づける) |
| 改ざん | 消す組織を取り違える | 試しの出力を見てから、組織の名前を打って確かめる(`--confirm-name`)。2人で |
| 否認 | 「消していない/消された覚えがない」 | 運営の組織の監査ログに、消した時刻・組織 ID・件数を残す |
| 情報漏えい(他社のデータ) | 書き出しに他社の行が混ざる | 書き出しも RLS の文脈の中で読む。結合テスト「他社の物が入らない」 |
| 情報漏えい | 書き出しの中に秘密(番号・Cognito の ID)が入る | 入れる項目を決めて写す(表を丸ごと出さない)。テストで確かめる |
| 妨害 | 書き出しを何度も押して DB を重くする | 管理者だけ。1ページずつ流し、メモリと接続は1回あたり一定(`docs/specs/0018-export-stream.md`・ADR 0031) |
| 権限昇格 | 代理の社員が書き出す | 代理は閲覧者なので 403 |

## やらないこと

- 大きな組織の書き出しを後で受け取る形(非同期で作って S3 から)。いまは1回の応答で、1ページずつ流して返す(2026-10-25 から。`docs/specs/0018-export-stream.md`・ADR 0031)
- 書き出しから戻す(インポート)
- 画面からの解約の申し込み・猶予期間つきの自動削除(作者 @attumkwg の選択で「削除は運営が」)
- 監査ログの保存期間を過ぎた分の削除(期間は契約で決まってから。消す仕組み `app.audit_purge` はこの PR の削除で使う)
- バックアップの中から1社だけ消すこと(できない。保存期間が来れば消える。テナントごとの鍵で「読めなくする」のは PMF 後)

## 決めたこと・人に判断してほしいこと

- 削除は API ではなくコマンド(ECS の1回きりのタスク。移行と同じ形)。ADR 0015。
- 書き出しの形は `format: "software-factory-starter/export@1"` を先頭に持つ JSON。形を変えるときは版の数字を上げる。
