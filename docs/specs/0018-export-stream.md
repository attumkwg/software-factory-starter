# 仕様: 大きい組織のデータの書き出し(少しずつ流す)

> 状態: 下書き(作者 @attumkwg の TODO「書き出しが1社の全データをメモリに載せる(大きい会社で API のメモリと ALB の60秒に当たる)」から AI が書いた。2026-10-25 に作者が並行のセッションで1本ずつ PR にすると決めた。承認は PR で)
> 設計: [docs/designs/0018-export-stream.md](../designs/0018-export-stream.md)
> 元の仕様: [docs/specs/0005-offboarding.md](0005-offboarding.md)(書き出しの中身・権限・監査ログは変えない)

## なぜ作るか

書き出し(`POST /api/exports`)は、1社の全部の行をメモリに載せてから返していた。大きい会社では、API のメモリが足りなくなる・全部を読み終えるまで1バイトも返らずに ALB の60秒(何も流れない時間)で切れる・1つのクエリの5秒を超える。画面も15秒で諦め、受け取った JSON を値に戻してから保存していた。解約のときに「持って出られる」(docs/security.md の T-9)が、大きいお客さんほど守れない。

## 受け入れ条件

- [ ] 管理者が書き出すと、今までと同じ形(`format: "software-factory-starter/export@1"` の1つの JSON・同じ項目)のファイルを受け取れる
- [ ] 大きい組織(数万行・中身が数十 MB)でも、API のメモリは中身の大きさに比例して増えない(1ページ分で一定)
- [ ] 大きい組織でも、最初のバイトはすぐ返り、そのあと何も流れない時間が ALB の60秒よりずっと短い(数秒以内)
- [ ] 受け手が遅い(途中で止まる)ときも、書き出しは切れない
- [ ] 受け手が途中でやめたら、残りは読まない(DB の接続を返す)
- [ ] 中身は欠けず重ならない(ページの境目・プロジェクトの境目・作った時刻が同じ行があっても)
- [ ] 他社の物は入らない(ページごとに RLS の文脈の中で読む)
- [ ] 途中で失敗したら、受け取ったファイルは完全ではないと分かる(途中で切れる)。失敗の中身(SQL・値・個人情報)は応答にもログの文にも出ない
- [ ] 書き出したことが監査ログに残る(今までどおり。流し始めた時点で)
- [ ] メンバー・閲覧者・代理の社員は書き出せない(403。今までどおり)
- [ ] 画面の「書き出す」は、大きいファイルでも15秒で諦めない(時間切れは応答が始まるまで)

## 権限の表に足す行

なし(`POST /api/exports` の行は 0005 のまま。admin 200・member 403・viewer 403・未ログイン 401)。

## 悪用のされ方(STRIDE で1行ずつ)

| 観点 | どう悪用されうるか | どう防ぐか(テスト / ルール) |
|---|---|---|
| なりすまし | 管理者になりすまして、全データを持ち出す | 今までどおり(管理者だけ・監査ログ)。持ち出しの鍵になる URL を作らない(署名つき URL の案を採らない。ADR 0031) |
| 改ざん | 該当なし(読むだけ) | — |
| 否認 | 「途中で切れたので書き出していない」 | 流し始めた時点で監査ログに残す(`offboarding.int.test.ts`・`export-stream.int.test.ts`) |
| 情報漏えい(他社のデータ) | ページの続きの印やトランザクションの開き直しで、他社の行が混ざる | ページごとに `withTenant`(テナントはセッションから)+リポジトリも `tenant_id` で絞る。続きの印はサーバーの中だけで受け渡し、リクエストから受け取らない(`export-stream.int.test.ts`) |
| 情報漏えい | 途中の失敗の文に、SQL の値や個人情報が出る | 応答は切るだけで文を返さない。ログは `logger.error({ err })` だけ(`export-stream.test.ts`) |
| 妨害(重い処理・大量の要求) | 書き出しを並べて、メモリ・接続を使い切る | メモリは1回あたり1ページ分。接続はページごとに短く1本(受け手が止まっても握らない)。受け手が切れば止まる(`export-stream.int.test.ts`) |
| 権限昇格 | 代理の社員が書き出す | 今までどおり 403 |

## やらないこと

- 非同期のジョブ(作って S3 に置き、署名つき URL をメール・画面で渡す)。ADR 0031 の見直す合図が来たら
- 形を変えること(JSON Lines・ZIP・表ごとのファイル)。export@1 のまま
- 1つの時点の写し(書き出しの途中の変更は、入ることも入らないこともある)
- 途中から続きを受け取ること(切れたら最初からやり直す)
