# 仕様: 画面の表側(検索に載せない・スマホの幅)

> 状態: 承認済み(承認した人: @attumkwg 2026-10-22。2026-10-21 の3回目の点検の 🔴 から)
> 設計: [docs/designs/0015-web-noindex-mobile.md](../designs/0015-web-noindex-mobile.md)

## なぜ作るか

2026-10-21 の点検で、画面の表側に2つの穴が見つかった。

1. **検索に載る**: `robots.txt` も `noindex` もどこにも無い。PR ごとのプレビュー(`pr-N.preview.<domain>`)も stg も公開の URL なので、リンクが1つ漏れれば、作りかけの画面や試しのデータの画面が検索に出うる。業務アプリなので、本番でもログインの後ろの画面が載る理由は無い。
2. **スマホの幅を確かめていない**: E2E はパソコンの幅(Desktop Chrome)だけ。表(監査ログは5列)や入力欄がスマホの幅で横にはみ出しても、だれも気づかない。押す所の大きさ(WCAG 2.2)も見ていない。

## 受け入れ条件

### 検索に載せない

- [ ] 本番以外(手元・プレビュー・stg・APP_ENV が無いとき)は、画面のサーバーの**全部の応答**に `X-Robots-Tag: noindex, nofollow` が付く
- [ ] 本番でも、**既定は全部の応答**に付く。外せるのは「公開してよいページ」の一覧に書いたパスだけ(ログインの後ろの画面は一覧に書いても本番以外では外れない)
- [ ] `/robots.txt` を返す。本番以外は `Disallow: /`(全部お断り)。本番は `/api/` だけお断り(noindex を読めるように画面は辿らせる)
- [ ] 静的なファイルの置き場(`apps/web/public`)があり、favicon を返す。画面のサーバーが SSR に回さずに返す
- [ ] 拡張子のあるパスで置き場に無いもの(`/favicon.ico`・`/wp-login.php` など)は、SSR に回さずに 404
- [ ] 無い URL(`/no-such`)を開くと 404 で「ページが見つかりません」が出る

### スマホの幅

- [ ] E2E にスマホの幅の組がある。主な流れ(ログイン → プロジェクト → タスク・列の多い表・無い画面)が通る
- [ ] E2E のアクセシビリティの検査が、どの画面でも「横にはみ出していない」(`scrollWidth <= clientWidth`)を確かめる
- [ ] アクセシビリティの検査に WCAG 2.2 AA(押す所の大きさ `target-size` など)が入る
- [ ] 表は、スマホの幅で列が入りきらないとき、**表の枠の中で**横に動く(画面全体は横に揺れない)
- [ ] 入力欄は、狭い幅では幅いっぱいまで縮む

## 権限の表に足す行

なし(API を足さない。画面のサーバーの応答のヘッダーと静的なファイルだけ)。

## 悪用のされ方(STRIDE で1行ずつ)

| 観点 | どう悪用されうるか | どう防ぐか(テスト / ルール) |
|---|---|---|
| なりすまし | 検索に載ったプレビューのログイン画面を本物と思わせる | プレビュー・stg は全部 noindex と `Disallow: /`(`app.test.ts`) |
| 改ざん | 該当なし(読むだけの応答) | — |
| 否認 | 該当なし | — |
| 情報漏えい(他社のデータ) | 作りかけの画面・試しのデータ・URL の中の ID が検索に残る | 全部の応答に noindex(本番も既定は全部)。`app.test.ts`・E2E `not-found.spec.ts` |
| 妨害(重い処理・大量の要求) | `/favicon.ico` や `.php` を探す機械の要求が、毎回 SSR(と API の読み)を動かす | 拡張子のあるパスは SSR に回さずに 404(`app.test.ts`) |
| 権限昇格 | 該当なし(画面のサーバーは権限を持たない) | — |

## やらないこと

- 本番で検索に載せるページを作ること(一覧は空のまま。U-1 で決めた)
- iPhone(WebKit)での E2E(CI に WebKit を入れるのは CI の変更=危険度「高」。次の一歩)
- API(`/api/*`)の応答への `X-Robots-Tag`(API は `robots.txt` でお断り。画面ではない)
- サイトマップ・OGP(公開のページを載せると決めたときに)

## 決めたこと

- 本番も全部のページを検索に載せない。ログイン・登録の画面も載せない(@attumkwg 2026-10-22「PR #6 の U-1 は『本番も全部検索に載せない』で承認します」。設計書の U-1)
