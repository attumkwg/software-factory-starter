# 仕様: 2つ目の客層の計画の置き場と、賭けの予算の枠

> 状態: 完了(実装済み。未確定事項は設計書で答え済み。@attumkwg が 2026-10-27 に完了とした)
> 設計: [docs/designs/0054-plans-and-bet-budgets.md](../designs/0054-plans-and-bet-budgets.md)・ADR: [0065](../adr/0065-bet-budgets-from-private-inputs.md)
> 穴 G-19(場面 1-7・4-7)。始め方の計画(`/kickoff`・`docs/product/plan.md`)と、費用のページの賭けごとの PL(仕様 0020)の上に積む。

## なぜ作るか

- 本業と別に「新しい客層」(例: 診療所の次に介護施設)を確かめたいが、`docs/product/plan.md` が1つだけで、2つ目の計画を本業と並べて持つ置き場が無い。
- ムーンショットに「半年・月 300万円まで」の枠を付けたい。使った額(人の時間を含む)は賭けごとの PL で見えるが、**枠と、超えそうなときの知らせ**が無い(AWS Budgets は環境ごと)。

## 受け入れ条件

> 「誰が・何をすると・どうなる」。どのテストかは設計書の「7. 要求との対応」。

計画の置き場(人と `/kickoff`・`/bet`):

- [ ] 本業の計画は今までどおり `docs/product/plan.md`。2つ目からの客層の計画は `docs/product/plans/<名前>.md`(同じ形)に置ける
- [ ] `/kickoff` は、計画が既にあって新しい客層の話なら「本業の続きか・新しい客層か」を聞き、新しい客層なら `plans/<名前>.md` に書く
- [ ] `/bet` は計画が2つ以上あればどの計画の賭けかを聞き、「親」に `plans/<名前>.md の仮説N` と書く

予算の枠(費用のページ):

- [ ] 人が賭けごとの月の枠(`bet,monthly_jpy,from,until,warn_pct`)を非公開の置き場の `budgets.csv` に書くと、費用のページに「賭けごとの予算の枠」の表が出る: 枠・今月これまで・月末の見込み・枠の何 %・期限・状態
- [ ] 使った額は賭けごとの PL の原価の上の端(人の時間・インフラ・SaaS・共通の配り分)。月末の見込みは、月の中で増える分を日割りで伸ばし、月額の SaaS はそのまま足す
- [ ] 見込みが枠を超える → 「超える見込み」、注意の線(既定 80%・行ごとに変えられる)を超える → 「注意」、期間を過ぎた枠 → 「期限を過ぎた」
- [ ] 注意か超える見込みの賭けがあれば、`cost.yml` がページを作った後に Slack(秘密がある時)と Actions の要約(非公開のリポジトリの時)に知らせる。**知らせに出すのは賭けの ID と割合だけ**(金額は出さない)
- [ ] 形の合わない行は数えず、数を「読めなかった物」に出す。枠はリポジトリに置かない

## 権限の表に足す行

API は足さない(権限の表に足す行は無い)。

## 要配慮個人情報

- 当たらない。枠は賭けごとの金額だけ。

## 悪用のされ方(STRIDE で1行ずつ)

| 観点 | どう悪用されうるか | どう防ぐか(テスト / ルール) |
|---|---|---|
| なりすまし | 該当なし(新しい入口が無い) | — |
| 改ざん | 枠を書き換えて、知らせを止める | 置き場に書けるのは人の役割だけ(ADR 0032)。枠を引き直すときは行を足す(古い行は残す)決まり |
| 否認 | 「いつ枠を変えたか」 | 置き場は版を残す。行を足す形なので、どの月から何円かが残る |
| 情報漏えい | 予算の金額が広まる | 枠は非公開の置き場だけ。Slack・要約は賭けの ID と割合だけ(テスト)。公開のリポジトリでは要約に出さない |
| 妨害 | 該当なし | — |
| 権限昇格 | 該当なし | — |

## やらないこと

- 期間の合計(半年で◯円)との比べ(費用のページは今月だけを集める。月ごとの写しは非公開の置き場にあるので、人が見る)。
- 枠を超えたら賭けを止める仕組み(決めるのは人。`/bet`)。
- 計画ごとの PL(計画は賭けの「親」で分かる。PL は賭けごと)。
- 新しい客層のための共通の基盤(要るまで作らない)。

## 決めたこと

- G-19 の中身(`plan.md` を複数持てる形・`/kickoff` が選ぶ・賭けごとの予算の枠(人の時間+インフラ)と超えそうなときの知らせ・費用のページの上に)は、親のセッションの依頼(2026-10-25)のとおり。
