## 第1部 PdM が書く所(業務の要求・業務ルール)

### なぜ作るか

タスクが完了したメール([仕様 0002](0002-task-completed-mail.md))は全部の組織に出た(B-0001 は adopted)。けれど、メールが要らない組織には止める手段が無く、「うるさい」と言われても運営が手で止めるしかない。B-0001 の撤退の線(「メールを止める組織が 50% を超えたら撤去を考える」)も、止める手段が無いので数えられない。

- ペルソナ: P-1・P-2([../product/personas.md](../product/personas.md)。見本)
- 動かす KPI: なし(B-0001 の K-2 は上げない。止めた組織には完了の知らせが届かなくなる)。数えるのは B-0001 の撤退の線「止めた組織の割合」(守り K-G8 を組織の粒度で)
- 意義の判断: 条件つき([../product/verdicts/2026-10-29-task-mail-switch.md](../product/verdicts/2026-10-29-task-mail-switch.md))。子の1と2で 4 人日を超えたら、3(画面)は作らずに判断し直す

### 業務の要求

- 組織の管理者が、その組織の「タスクが完了したメール」を止められる・また送るように戻せる
- 止めた組織の数を数えられる(B-0001 の撤退の線を見るため)

### 業務ルール

- 止める・戻すは組織ごと(未確定 U-1) — B-0001 の撤退の線が組織の数で決まっている。人ごとに止めると線を数えられない(仮説)
- 止める・戻すのは管理者だけ — 組織の中の全員に届くかどうかを1人の member が決めない(二段階認証の必須と同じ扱い)
- 既定は「送る」 — いま全部の組織に出ている(adopted)。黙って止まる組織を作らない
- 止めたら、その後に完了したタスクのメールは送らない。止める前に完了して、まだ送っていない物も送らない — 「止めたのに届いた」を作らない
- 戻しても、止めていた間に完了したタスクのメールは後から送らない — 古い知らせをまとめて届けない

### 受け入れ条件(業務の言葉で)

- [ ] 管理者が設定の画面でメールを止めると、その組織でタスクが完了しても、プロジェクトを作った人にメールが届かない
- [ ] 管理者が戻すと、その後に完了したタスクのメールは前と同じように届く
- [ ] 管理者でない人(member・viewer)には、止める・戻すの操作が出ない
- [ ] 止めた・戻したは監査ログに残り、誰がいつ変えたか分かる
- [ ] 止めている組織の数を、運営が数えられる(組織の名前は要らない)

### 要配慮個人情報

- 当たらない(「送る・送らない」の1つの値だけ。人が書く欄は無い)(未確定 U-2)

### やらないこと

- 人ごとに止める(U-1 の答えで変わる。今は組織ごと)
- ほかのメール(招待・アカウントの知らせ・規約の知らせ)を止める — 守りと契約の知らせは止めさせない
- まとめて1通にする・送る時刻を選ぶ(B-0002 の朝のまとめの話)

### 決めたこと

- (人がまだ答えていない。U-1・U-2 は設計書の未確定事項に `仮決め` で残す)

## 第2部 AI が網羅して書き、エンジニアが見る所(システムの振る舞い)

### 状態 × 操作

| 状態 \ 操作 | 止める(管理者) | 戻す(管理者) | タスクが完了した | 送る直前(アウトボックスの受け手) |
|---|---|---|---|---|
| 送る(既定) | 止まる。監査ログ `organization.task_mail_off` | 変わらない(204。監査ログは残る) | 出来事を積む(今のまま) | 今のまま送る |
| 止めている | 変わらない(204。監査ログは残る) | 送るに戻る。監査ログ `organization.task_mail_on` | 出来事を積む(今のまま。止めたかは送る直前に見る) | 送らない(`skip: mail_off_by_organization`) |

- 止めたかは**送る直前**に見る(出来事を積むときではない)。止める前に積んだ出来事も、止めた後に送るなら送らない。戻した後に、止めていた間に積んだ出来事が届くことはない(アウトボックスはその時点で済みにする)。

### 境界値

- 値は「送る / 止める」の2つだけ。同じ値をもう1回送っても 204(冪等)
- 止めた直後に完了した物: 送る直前に読むので送らない
- 止めた直前に完了して、受け手がまだ動いていない物: 送らない(業務ルールのとおり)
- 戻した直前に止めていた間の出来事の再送(アウトボックスの「少なくとも1回」): 済みにした出来事は再送しない

### 権限の組み合わせ

| API | admin | member | viewer | 他社 | 未ログイン |
|---|---|---|---|---|---|
| `GET /api/organization/task-mail` | 200 | 403 | 403 | —(自分の組織だけを指す) | 401 |
| `POST /api/organization/task-mail`(戻す) | 204 | 403 | 403 | — | 401 |
| `DELETE /api/organization/task-mail`(止める) | 204 | 403 | 403 | — | 401 |

- [ ] member・viewer が止めようとすると 403
- [ ] 他社: パスに組織の ID が無く、セッションの組織だけを指す(他社の設定を指す道が無い)
