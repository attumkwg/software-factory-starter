# 仕様: 続けて提供できるか(SPF)の段

> 状態: 承認済み(承認した人: @attumkwg 2026-10-25。U-1 はキットの既定として承認し、導入時に決める)
> 設計: [docs/designs/0049-spf-stage.md](../designs/0049-spf-stage.md)

## なぜ作るか

- フィットジャーニー(CPF → FPF → PSF → SPF → PMF)のうち、SPF(解決策を続けて提供できるか)の段が無い。手作業の裏方を何で置き換えるか・1社あたりの手間と原価・誰が回すかが決まらないまま社数が増え、PMF の手前で人が足りなくなる(想定の場面の `00-best-case-run.md`・`fit-journey.md` の SPF の行)。
- 1社あたりの原価は費用のページで出せるようになった(`docs/guides/cost-dashboard.md` の 7)が、計画の側に比べる所が無い。

## 受け入れ条件

- [ ] 計画のひな形 `docs/product/_template.md` に「続けて提供できるか(SPF)」の節があり、手作業の裏方の表(手作業・誰が・1社あたりの分・何で置き換えるか・いつまでに)・1社あたりの手間と原価(金額は書かず割合か足りる / 足りない)・誰が回すか(役割・休んだら誰か)・SPF の線(合格・撤退・期限)がある
- [ ] `/kickoff` の B(結果を持ち帰った)に、PSF の後か有料の顧客が付いたら SPF を1つずつ聞く段があり、費用のページの1社あたりの原価を見せ、線と比べて進む・変える・やめる・意思で進むの案を出す。まとめの確認にも SPF の行がある
- [ ] 線は目安で、届かなくても意思で進んでよい(ADR 0035)と書いてある
- [ ] `docs/guides/before-pmf.md` に SPF の節がある
- [ ] plan.md に金額・人の名前を書かない決まりがある

| 観点 | どう悪用されうるか | どう防ぐか(テスト / ルール) |
