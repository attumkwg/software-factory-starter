## なぜ作るか

2026-10-21 の点検で、画面の表側に 🟡 が4つ残った。

1. **リンクを貼っても何の画面か分からない**: どの画面にも説明(meta description)と OGP が無い。ログインの画面や利用規約のリンクを Slack や Teams に貼ると、カードに「Tasks」としか出ない。
2. **ホーム画面のアイコンが無い**: favicon は SVG だけ(#6)。iPhone のホーム画面に置くと、画面の縮小画像になる。
3. **狭い画面の確かめが主な流れだけ**: 表は表の枠の中で横に動き、入力欄は親の幅まで縮むようにした(#6)。ただしスマホの幅の E2E が見ているのは、ログイン → プロジェクト → タスク・監査ログ・無い画面だけ。サポートへの許可(表と選択)・設定・規約の本文・サポートの入口(入力)は、スマホの幅で一度も開いていない。
4. **無い URL の 404 が浅いパスだけ**: `/no-such` は 404 を確かめた(#6)。深いパスと、ログインの後ろの画面の形をしたパス(`/projects/<無い>/<余分>`)は確かめていない。

## 受け入れ条件

### 説明と OGP

- [ ] 画面ごとに、title・説明・OGP(`og:title`・`og:description`・`og:type`・`og:url`・`og:site_name`・`og:locale`、要るなら `og:image`)を1つの関数(`pageHead`)で出せる
- [ ] 公開の画面(ログイン・登録・パスワードの再設定・利用規約・プライバシーポリシー)が、その画面の説明と OGP を出す
- [ ] 説明を書かない画面は、プロダクトの既定の説明を出す
- [ ] `og:url` と `og:image` は絶対 URL。画面の URL は環境変数 `APP_URL`(API と同じ名前)から。無いときは出さない(相対の URL を出さない)
- [ ] `og:url` に `?` 以降を載せない(戻り先などを外に出さない)
- [ ] **検索に載せない決まり(#6)と食い違わない**: OGP を出す画面にも `X-Robots-Tag: noindex, nofollow` が付いたまま。`<meta name="robots">` は出さない(載せるかを決めるのは画面のサーバー1か所)

### アイコン

- [ ] `/apple-touch-icon.png`(180×180)を返し、`<link rel="apple-touch-icon">` で指す。形は favicon.svg と同じ

### 狭い画面

- [ ] スマホの幅(320px)で、サポートへの許可・設定・規約の本文(今の版と前の版)・サポートの入口が横にはみ出さず、axe を通る

### 無い URL

- [ ] 深いパス(`/no/such/page`)も 404 で「ページが見つかりません」が出る
- [ ] 「ページが見つかりません」の画面に、最初の画面(`/`)へのリンクがある(行き止まりにしない)
- [ ] バッジ(札)は狭い列でも1文字ずつ折り返さない
- [ ] ログインの後ろの画面の形をした無いパス(`/projects/no-such/extra`)は、ログイン前はログインの画面へ回し(あるかどうかを明かさない)、ログインした人には 404 で「ページが見つかりません」が出る

## 権限の表に足す行

なし(API を足さない。画面の `<head>` と静的なファイルだけ)。

## 悪用のされ方(STRIDE で1行ずつ)

| 観点 | どう悪用されうるか | どう防ぐか(テスト / ルール) |
|---|---|---|
| なりすまし | よその URL を `og:url` に入れさせ、カードの行き先を偽る | `og:url` の元は環境変数だけ(要求の値を使わない)。パスは `/` から始まるものだけ(`head.test.ts`) |
| 改ざん | 該当なし(読むだけ) | — |
| 否認 | 該当なし | — |
| 情報漏えい(他社のデータ) | ログインの後ろの画面の名前(プロジェクトの名前)が OGP でカードに出る | ログインの後ろの画面には `og:url` を付けない。未ログインのカードの取得はログインの画面へ回るので、中身は出ない。`?` 以降を `og:url` に載せない(`head.test.ts`) |
| 妨害(重い処理・大量の要求) | 該当なし(`<head>` の文字が増えるだけ。アイコンは #6 の静的なファイルの置き場から) | — |
| 権限昇格 | 該当なし | — |

## やらないこと

- 検索に載せること(本番も全部 noindex のまま。#6 の U-1)。サイトマップ・構造化データ
- 公開ページのキャッシュ・LCP / CLS の測定(SEO のサイト型のときに)
- 画面のスクリーンショットの比較(VRT。作者が「後日でいい」)
- 既定の OGP の画像(`og:image`)。関数は受け取れるが、キットとしての画像は置かない(プロダクトの絵が決まってから)
- stg・prod の画面のサービスに `APP_URL` を渡すこと(Terraform は危険度「高」。人が別の PR で。設計書の 8)
