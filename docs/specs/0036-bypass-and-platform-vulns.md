# 仕様: 確認を飛ばすモードの禁止と、基盤の穴の作り直しと出し直し

> 状態: 承認済み(承認した人: @attumkwg 2026-10-25。会話で: 穴を足す順番を決め、TODO を解消していってほしい)
> 穴: `docs/scenarios/gaps.md` の G-23・G-24。場面: `06-security-audit.md` の 6-3・6-12、`07-grow.md` の 7-7

## なぜ作るか

- 2025 年に、乗っ取られた依存が、開発者の端末に入っている AI の CLI を確認を飛ばす旗で呼び、鍵を探させた攻撃があった。キットは確認を飛ばすモードを禁止していない。
- 2026-10-21 に Node.js(22・24・26 系)に重い穴の直しが出た。キットのイメージは版を固定しないタグなので作り直せば直るが、作り直して出し直す手順が無い。手元の処理系は Renovate が見ない。

## 受け入れ条件

- [ ] このリポジトリで動く Claude Code は、確認を飛ばすモード(bypassPermissions)を使えない(`.claude/settings.json`)
- [ ] 社員の端末に配る設定の考え方(管理者の設定・エンジニアとそれ以外で分ける・中身の例)が `docs/guides/local-guards.md` にある
- [ ] 基盤の穴の手順書 `docs/runbooks/platform-vuln.md`(どこに当たるか・土台のイメージ・作り直し・stg → 本番・手元の処理系・corepack の注意)があり、`/cve` と `docs/guides/vulnerabilities.md` からたどれる

なし

## 悪用のされ方(STRIDE で1行ずつ)

| 観点 | どう悪用されうるか | どう防ぐか(テスト / ルール) |
|---|---|---|
| 権限昇格 | 乗っ取られた依存が、AI の CLI を確認なしで呼ぶ | 確認を飛ばすモードの禁止(このリポジトリの中)・端末に配る設定(外) |
| 改ざん | 直ったつもりで古いイメージが動き続ける | 手順書の 2・3(作り直しと出し直し・版の確認) |
| そのほか | — | — |

## やらないこと

- 管理者の設定の配り方そのもの(MDM の操作。情シス)
- イメージを digest で固定する(作り直せば直る今の形を保つ)

## 決めたこと

- 確認を飛ばすモードはこのリポジトリでは使わない(ADR 0047)
