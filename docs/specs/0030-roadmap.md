> 穴: `docs/scenarios/gaps.md` の G-07。場面: `docs/scenarios/03-roadmap-build.md` の 3-2

## なぜ作るか

営業が商談で「いつ出るか」を聞かれ、代表は展示会で次の3か月の予定を1枚で見せたい。いまは `pnpm bets` が賭けの一覧を出すだけで、「いま確かめている・次にやる・定着した」を並べた1枚が無い。

## 受け入れ条件

- [ ] `pnpm bets --roadmap` が、賭けを「いま確かめている(cpf・psf・rollout)・次にやる(idea)・定着した(adopted)・やめた・撤去した」に分けた社内の版を出す(段階・何を・親・次に決める日。⚑ 意思で進んだ・⏰ 決める日を過ぎた)
- [ ] `pnpm bets --roadmap --public` が、時期を約束しない社外の版を出す(題名と段階の言い換えだけ。親・日付・賭けの ID・やめた物は出さない)
- [ ] `--write` で `docs/product/roadmap.md`・`docs/product/roadmap-public.md` に書く。賭けの書き方に問題があれば作らない
- [ ] `docs/guides/bets-and-assets.md` に使い方がある
