# 仕様: 画面の CSP(Content-Security-Policy)

> 状態: 完了(実装済み。未確定事項は設計書で答え済み。@attumkwg が 2026-10-27 に完了とした)
> 設計: [docs/designs/0045-web-csp.md](../designs/0045-web-csp.md)・ADR: [0056](../adr/0056-web-csp-with-nonce.md)
> 穴 G-17(`docs/scenarios/gaps.md`)。想定の場面 6-7(外部の診断)。

## なぜ作るか

- 画面に CSP が無い。外部の診断ではほぼ必ず指摘される(想定の場面の 6-7)。
- CSP が無いと、どこかで HTML に差し込まれたスクリプト(XSS)が、そのまま利用者のブラウザで動く。画面は React で描くので差し込みは起きにくいが、起きたときの最後の守りが無い。
- これまで見送っていた理由は「SSR が埋め込むスクリプトに nonce が要る」(`docs/security.md`)。TanStack Start は nonce を受け取って埋め込みに付けられる。

## 受け入れ条件

- [ ] 画面のサーバーの全部の応答に `Content-Security-Policy` が付く。スクリプトとスタイルは、自分の origin の物と、その応答の nonce の付いた埋め込みだけを許す
- [ ] nonce は1リクエストごとに変わる(16バイトの乱数)。ブラウザから送られた nonce の値は使わない
- [ ] SSR が埋め込むスクリプトには、その応答の nonce が付く
- [ ] `eval` の類(`'unsafe-eval'`)・`object`・`base` を止め、よそのサイトに枠で埋め込ませない(`frame-ancestors 'none'`)
- [ ] ブラウザから外へ送るのは、Sentry の DSN があるときのその origin だけ(`connect-src`)
- [ ] 主な画面(ログイン・規約・見つからない・部品の一覧・ログインの後のプロジェクト・設定)を開いて操作しても、CSP の違反が1つも出ない(E2E。出たら落ちる)
- [ ] nonce の無い埋め込みのスクリプトは、本当に止まる(E2E)
- [ ] 見た目は変わらない(VRT の基準のまま)

## 権限の表に足す行

該当なし(API を足さない)。

## 要配慮個人情報

- 当たらない(ヘッダーだけ)。

## 悪用のされ方(STRIDE で1行ずつ)

| 観点 | どう悪用されうるか | どう防ぐか(テスト / ルール) |
|---|---|---|
| なりすまし | よそのサイトが画面を枠で埋め込み、押させる(クリックジャッキング) | `frame-ancestors 'none'`(単体) |
| 改ざん | 差し込まれたスクリプトが画面を書き換える・Cookie の無い操作を API に送る | nonce の無い埋め込みは止まる(E2E)・`'unsafe-eval'` 無し(単体) |
| 否認 | 該当なし | — |
| 情報漏えい | 差し込まれたスクリプトが、画面の中身をよそへ送る | `connect-src` は自分と Sentry の origin だけ。`img-src` も自分と `data:` だけ(単体) |
| 妨害 | 該当なし | — |
| 権限昇格 | ブラウザから `x-csp-nonce` を送って、nonce を決めさせる | 受け取った値は捨て、サーバーが作った値だけを SSR に渡す(単体) |

## やらないこと

- 違反の知らせを受け取る口(`report-to`)。違反は E2E で見つける
- 手元の開発(`pnpm dev`)の CSP(画面のサーバーを通らない)
- API の応答の CSP(HTML を返さない)
